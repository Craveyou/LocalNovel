目录

漫画 / 小说 / 整理的目录结构

漫画：文件夹名就是漫画名，可以只有「话」，也可以中间夹「部 / 单行本」当卷名。

漫画/
├─ 星海旅人/            ← 文件夹名 = 漫画名（一本）
│  ├─ 第1部/            ← 中间层 = 卷名
│  │  ├─ 第1话/         ← 放图片的文件夹 = 一话
│  │  │    001.jpg 002.jpg …
│  │  └─ 第2话/
│  └─ 第3部/第1话/…
├─ 深海食堂/
│  ├─ 第01话/001.jpg
│  └─ 第02话.pdf        ← 一个 pdf = 一话
├─ 夜行列车/            ← 同一部书按格式分成两个包
│  ├─ PDF包/第01话.pdf
│  └─ 图片包/第01话/001.jpg
└─ 短篇合集/单行本/第3话/…
漫画名文件夹一部漫画，列表里的一本
中间文件夹卷名；多层用「 · 」连接，如「第1部 · 第2话」
有图片的文件夹一话；只看该层自己的图片，不含子文件夹里的
每个 pdf一话，按页渲染，滑到哪页生成哪页
格式包（PDF包 / 图片包）包名就是分组名，章节列表按包分段，两包各自列出
漫画名层散图整部只有一话，标题用漫画名
排序先按分组、再按话名自然排序：第2话 排在第10话 前面

小说：一个文件一本（txt / md / epub / pdf）；子文件夹 = 一个系列，再嵌一层是「系列 · 子系列」。只有小说用左右翻页，设置里可改滚动。

小说/
├─ 风起长安.txt
└─ 银河旧事/            ← 系列
   ├─ 第一部 启程.txt
   └─ 前传/前传.txt      ← 「银河旧事 · 前传」

短剧：剧名/剧照（图片）+ 剧名/视频（mp4）两个包；剧照按漫画方式连排，视频行显示大小与时长。

整理：作者名/章节名/正文.txt + 按序号图片 + 音视频，始终上下滚动。

隐藏文件、Thumbs.db、desktop.ini、放书说明.txt 不参与扫描；不认识的扩展名会在阅读页提示「已忽略」。
