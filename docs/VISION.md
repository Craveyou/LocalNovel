# XLib 产品愿景

跨客户端能力与实现范围以 [产品能力体系](product/README.md) 为入口；下方平台文档仅约束各自实现。

XLib 的目标是提供一致、可靠的本地书籍与文档阅读体验，同时保持离线优先、可靠阅读位置和大文件低内存能力。现有客户端支持 TXT；新增 PDF、EPUB 计划采用 Android 先行、验证后再实施 iOS。未来 macOS 的新格式范围尚未评估。先 PDF 后 EPUB，密码输入及搜索/书签/复制/阅读进度同步纳入 0.13.0；需求与兼容范围见 [多格式阅读](product/multi-format-reading.md)。

## 核心原则

1. 阅读位置按格式定义：TXT 仍以原始文件绝对字节 offset 为权威，PDF/EPUB 各自定义页面或内容定位；百分比只用于派生展示和粗粒度跳转。
2. 客户端离线时功能完整；同步是可选能力，不能成为阅读前置条件。
3. 不上传书名、正文、本地路径或原始文档文件；PDF/EPUB 同步已确认纳入 0.13.0，但须先扩展类型化定位协议，现有 TXT v1 不能直接承接新格式位置；不上传文档密码。
4. 各平台使用原生界面，共享的只是经验证的平台无关核心和 HTTP 合同。
5. 构建、测试和发布必须可重复；普通构建只递增平台 build 号，不隐式修改组件版本名或源文件。

完整交互与验收规范按平台区分：Android 见 [features/reader.md](features/reader.md)，iOS 当前实现见 [features/ios.md](features/ios.md)。
