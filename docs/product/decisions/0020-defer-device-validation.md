# Decision 0020：功能优先，真机联合验收后置

日期：2026-10-25

状态：accepted，来自用户明确指令；调整执行顺序，不表示任何待测项通过。

## 用户决定

当前无法连接 iPhone。用户要求调整工作计划：真机性能，以及需要连接 iPhone 的压力/样本测试，移到后面与其他功能的性能测试一起完成；现在先完成其余功能和界面需求。

## 对实施顺序的修订

- 不再以完整漫画 G1（包含物理设备测试）作为 Kindle 功能开发的开工门槛；此项覆盖 Decision 0019 和原交付计划中相应的串行限制。
- 当前推进漫画功能/界面补齐与可在宿主/模拟器完成的回归，并开展第二批公共核心、共享规范/样本、iOS Kindle 功能及对应测试。Android 继续消费公共产物，并行维护本端。
- 全部需要连接 iPhone 的性能、压力、真实文件提供商/磁盘环境和设备样本测试，集中到全格式功能完成后的联合设备验收；不反复要求当前连接设备。
- 不依赖物理设备的损坏/恶意文件、路径安全、资源限额、取消、迁移、契约和界面测试继续随开发执行，不把基本安全和数据保护推迟到最后。

## 未改变的约束

- 后置不是免测或验收通过。G1/G2 分别记录功能/界面证据与设备待验收项，G3 整版完成前仍须补齐双方适用的设备结果与预算。
- 公共规范与机器契约未就绪前，不正式保存/上传 Kindle 坐标；同一正文真值、混合统一选 KF8、拒绝 DRM、离线阅读和数据保护规则不变。
- 不缩减格式范围，不冒用旧版本/模拟器数据作为本轮真机性能结论，不提前改版本/清单、签名、部署、commit 或 push。

具体顺序、待办和证据见 [0.14.1 计划](../plans/0.14.1.md)及[交接记录](../plans/0.14.1-agent-handoff.md)。
