# 0.13 Android 已沟通范围后续补齐

日期：2026-10-23。依据 [0.13 计划](0.13.0.md)、[Android 交互说明](../../../apps/android/README.md) 和前轮模拟测试，补齐既有功能的实际缺口；不新增 OCR、DRM、批注或自动翻页等格式范围。开发版本名保持 0.12.0，未创建分支、未 commit、未 push。

## 本轮完成

| 已沟通范围 | 缺口与修改 |
|---|---|
| PDF 全书搜索性能 | 每页文字提取原先都会遍历整棵页树；改为一次解析页引用并直接处理目标页。扫描只生成原文，命中页面再生成定位坐标；正则表达式每个搜索任务只编译一次。无磁盘文本索引或解密副本 |
| 搜索停止及任务隔离 | PDF/EPUB 搜索执行中显示“停止搜索”，返回可取消；新查询先取消旧任务，后台/退出取消搜索。迟到结果与取消异常不能弹出旧结果或错误，状态恢复为实际阅读位置 |
| 从书首搜索及临时阅读 | 新格式搜索表单增加“从书首搜索”，默认当前正文位置；保留分批和主动回绕，重新搜索保留输入。查看结果及返回不重置正式位置或时间 |
| 阅读偏好 | PDF/EPUB 读取现有“保持屏幕常亮”设置，前台设置、后台清除；EPUB 明暗主题保存到原有偏好，关闭重开仍生效，排版不创建阅读事件 |
| EPUB 滚动与选文生命周期 | 拖动松手立即采集正文锚点，后续滚动继续合并保存；后台迟到的滚动不提交进度。切后台清理临时选区 |

原有书架左滑/长按删除、TXT 进度数字和轨道反差、持续拖动扩选已有实现，本轮保留为回归基线。无需重复新增相同入口。

## 千页 PDF 最终复测

沿用原报告同一自建 `pdf-large.pdf`（1,000 页、440,028 B，SHA-256 与原 manifest 一致），最终 build 86 在专用 API 35 模拟器完成 **3 轮、30 次导航**，搜索分批、全书无命中、取消、关闭恢复及正式时间隔离断言均通过。计时负载顺序运行，不与编译任务并行；未清 OS 缓存。环境为软件图形模拟器，非真机。

| 指标 | 三轮中位数 / 采样结果 |
|---|---:|
| 导入 | 92.4 ms |
| 打开（原生渲染就绪及下一 UI 帧） | 792.5 ms |
| 导航中位数 / 最大值 | 85.2 / 277.8 ms |
| 首批 / 第二批搜索 | 299.3 / 163.7 ms |
| 全书无命中 | **6441.2 ms** |
| 取消请求至任务退出 | 4.0 ms |
| 应用 PSS 三轮采样峰值最大值 | 128.8 MiB |

历史模拟基线的全书无命中中位数为 9535.3 ms，本轮约减少 32%；AVD 由之前的 `xlib013-performance` 改为本轮专用 `xlib013-validation`，不作为严格受控的真机速度承诺。仍需约 6.4 s 扫描完整本，不能以首批约 0.3 s 代表全书搜索已无延迟。

优化分两阶段验证：仅消除重复页树遍历时仍约 8 s；再按需生成命中页面的选区几何后得到上表。阶段日志与最终日志分开，原双端 36 轮基线保留不覆盖；本轮原始 JSON 和统计表分别在 `performance/measurements.json`、`performance/results.md`。

## 剩余验收

支持子集内功能已经有模拟器证据；复杂真实文件、低端真机、长时间切书、明确性能预算和最终版本验收仍需执行。全书扫描较首批结果慢，停止入口只能中止继续扫描，不能使当前 PDFBox 页解析瞬时结束。模拟测量不替代真机或发布验收，当前不升级为 0.13.0。
