## 2. 位置和阅读事件

- 身份为**原文件 SHA-256 + 原文件字节大小**，加密 PDF 不重写身份。TXT 继续走原 v1 字节位置；PDF/EPUB 走 `/v2/progress`，不写伪 byte offset。
- PDF locator v1：从 0 开始的页面索引、页数、视觉页面内归一化 `y`（六位小数）；界面显示索引 + 1。进度为 `(page+y)/pageCount`。文档自带页标签、PDF 大纲和高级内链接尚无专门入口。
- EPUB locator v1：规范化正文资源路径、spine 索引/数量、正文 DOM 文本的 UTF-16 offset/length。文本保留组合字符与空白；不含作者脚本和样式节点。进度为各 spine 单元等权加章内比例，不代表整本字符数量比例。
- 打开、恢复、缩放、重排、选文、搜索预览不刷新正式阅读时间。翻页、章节/目录/内部正文链接与脚注导航、有效页内平移/正文滚动产生正式位移。接受云端位置须成功呈现并保存，保留远端原时间。
- 书签、正式进度和搜索命中使用同一定位语义，搜索会话独立；关闭搜索可返回正式阅读位置。云端删除与上传串行，成功后本次会话持续暂停上传，退出重开才重新比较。
- 后端独立保存类型化进度，旧 TXT v1 兼容；单书删除同时清理同身份的旧/新进度空间。未知定位版本、未知字段、路径越界和无效数值明确拒绝。

规范详见 [API](../../API.md)、[本地存储契约](../../architecture/local-storage-contract.md) 和 [共享坐标夹具](../../../contracts/fixtures/documents/coordinates.json)。

## 3. 当前支持子集与限制

### PDF

Android 使用 Apache-2.0 的 PDFBox Android **2.0.27.0**；iOS 使用系统 PDFKit。已验证普通文本、无文本层页面、禁止提取文本页面、128 位打开密码的正确/错误/重试/重开，以及 Android 0/90/180/270 度页面文字区域对齐。未测的加密算法和复杂字体不标为兼容通过；无文本层不执行 OCR。

Android 原文件上限 256 MiB，PDFBox 主内存缓冲预算 96 MiB，页图像宽度最多 1600、像素数最多约 400 万；这不是应用总内存上限或真机性能承诺。JPX/JBIG2 图像编码会明确报不支持，避免将缺失页面内容当作成功。两端均不在磁盘建立解密正文或文本索引。

### EPUB

支持无 DRM、可重排的 EPUB 2/3 UTF-8 XHTML 文本/图片与本地 CSS；按 OPF spine 阅读，支持 nav/NCX 目录和有效正文锚点。固定版式、音视频、DRM、加密资源（含加密字体）不在当前支持子集。作者脚本不执行，网络资源不自动加载；外部链接需用户确认。

压缩包文件上限 256 MiB、资源数 10,000、单资源 16 MiB、总展开量 256 MiB；同时限制压缩膨胀、正文解析深度/节点数量与正文内存。两端使用共享 HTML 实体与坐标夹具，不把 WebView 排版页号作为正式位置。

Android 一批最多 5 本 PDF/EPUB，TXT 原 20 本规则保留；这是当前保护限额，尚无代表性设备性能测量支撑。iOS 当前使用单文件选择流程。导入失败和取消会补偿文件/数据库状态，启动时只清理应用管理的无引用文件。
