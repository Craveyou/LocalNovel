状态：**同一临时服务上的完整五阶段已通过**（2026-10-24，Android build108 / iOS build123–124，均为模拟器）。此项补齐跨端接续子项，不代替完整 G1。2026-10-25 用户已通过 [0020](../decisions/0020-defer-device-validation.md) 单独调整开工顺序：设备验收后置，不再阻塞 Kindle 开发；不是由本次模拟器结果自动解除门槛。

## 目的与边界

补齐 R014-03/06/12 的同原包清单、定位与时间优先接续证据，不再以两个 Android 或两个 iOS 身份各自通过代替跨端。四种原包共用相同 24 页及 comic-order-v1 清单，但各自保持原始 SHA-256 + fileSize 身份：

- comic-basic.cbz
- comic-basic-rar4.cbr（RAR4 stored）
- comic-basic-rar5.cbr（RAR5 stored）
- comic-basic-rar4-solid.cbr（RAR4 compressed-solid）

使用真实 Android instrumentation、iOS URLSession / DocumentReaderModel、HTTPS API 和独立 PostgreSQL 17，不用宿主 HTTP 脚本伪装任一客户端。iOS 用测试回调确认 renderer 命令，坐标来源仍为真实原包/清单；此处不是 UI 点按或真机性能测试。图像、手势及旋转 UI 回归另见[实施记录](0.14.1-comic-implementation.md)。

## 五阶段接口

同一次根命令内复用一个临时服务与随机账户 `run + '-cross-comic@example.com'`。只有短期测试凭据，不读取生产配置或用户身份，不输出 Token，不安装系统证书。

| 阶段 | 执行方 | 预期动作/断言 |
|---|---|---|
| seed | Android | 从四原包解析正式身份与清单，写入 page10 / y=0.234567（显示第 11 页） |
| accept-android | iOS | 验证来源 android、清单/页 key 和原时间；正式会话接受不制造新事件，再实际移动到 page11 / y=0（第 12 页、50%）并上传；较早/较新异清单都 422 且旧行不变 |
| accept-ios | Android | 正式会话接受 iOS 位置/时间，不另造阅读时间；再实际向前回退到 page10 / y=0.500001，以较新的实际时间上传 |
| accept-android-delete | iOS | 接收较前页但较新时间的 Android 状态，保留原时间；只删本书云端位置，本次会话继续移动/刷新不得重建云端行，本地位置继续保存 |
| verify-deleted | Android | 确认四本进度均为空，TXT v1 隔离；不启动一个会重新上传的新正式阅读会话 |

每阶段覆盖全部四原包。iOS 两阶段复用固定测试设备 UUID，但只在本次随机账户下生效。Android 的 `apps/android/scripts/test-cross-comic-stage.sh` 消费 `XLIB_COMIC_INTEROP_STAGE`，映射到 instrumentation `interopStage`；已安装 APK/可用模拟器与最终命令以 [Android 分阶段交接](../../../apps/android/docs/0.14.1-cross-comic-interop.md)为准。

## 自动执行

前提：Android owner 已构建并安装支持分阶段入口的 app/test APK，选定一个可用的专用模拟器；iOS 的 `XLib Test iPhone` 已启动。公共脚本不编译/安装/重置 Android，不抢占其他任务的在途设备测试。

```sh
ANDROID_SERIAL=emulator-5554 make test-comic-cross-client-interop
```

根目标先校验并构建 Backend，再由 `scripts/test-comic-cross-client-interop.sh` 和既有 `start-document-interop-test.sh` 创建同一个 HTTPS/PG17 沙箱。每个阶段失败即失败退出，自动停止临时服务/PG；Android 脚本清理本阶段端口转发。不会改签名、部署、commit 或 push。

iOS 通过 `TEST_RUNNER_XLIB_COMIC_INTEROP_STAGE` 向测试进程注入 `XLIB_COMIC_INTEROP_STAGE`，仅运行 `DocumentInteropTests/testComicAndroidIOSStagedHandoff`。未注入所需环境时明确 opt-in 跳过，不当作跨端通过。结果包在 `artifacts/ios-tests`，两阶段是同一个用例的两次执行，不跨轮累计成不同测试。
