# 0.14.1 iOS 非设备功能与界面补齐

日期：2026-10-25。按用户 [Decision 0020](../decisions/0020-defer-device-validation.md) 执行，先交付功能/界面，需要 iPhone 的性能/压力/样本留到全格式完成后联合测试。本记录不是完整 G1/G2/G3 或整版完成结论。

## 本轮变更

- 漫画目录、书签和设置面板沿用 TXT 的 `XLGlassToolbar` 标题栏；设置改用现有 `SettingsSection` / `SettingsDivider` 玻璃卡片、主题和控件，不展示第二套默认导航/表单外观。
- 空书签提供与 TXT 相同的操作指引。保存成功给出可读的“书签已保存”反馈，重复位置继续提示错误，不新增重复书签；成功反馈三秒后自动消失，后续消息会取消旧清理任务。
- 加载/渲染/比较期间，保存书签、进度选择、目录定位及云端操作按就绪状态禁用；模型自身也拒绝未准备好、未完成渲染、后台或关闭后的书签写入。加载期间保留返回书架入口。
- 书签预览仍是临时状态，可以返回正式位置；单条删除保留确认/取消流程。界面内错误在当前面板展示，不藏在面板后。
- 设置中的云端删除先完成面板关闭，再显示确认，避免两个呈现过程竞争；失败保留本地位置并沿用 TXT 的错误弹窗。保留 iOS 原生确认行为：popover 模式可以不显示取消按钮，点击外部是取消，不执行删除。
- 增加缺失原文件的错误/重试/返回流程测试；仅在 DEBUG 且有效随机 UI 测试 ID 的独立 `XLibUITests-<id>/Books/` 容器中移除夹具，不碰用户书库。

## 验证方式与结果

根入口（已启动的 XLib Test iPhone / iOS 26.5 / arm64）：

```sh
make test-ios IOS_TEST_ARGS='-collect-test-diagnostics never -only-testing:XLibReaderTests/ComicReaderTests -only-testing:XLibReaderTests/DocumentReaderTests -only-testing:XLibReaderUITests/ComicFlowUITests'
```

完整定向回归 build128：27 项模型测试全部通过；6 项漫画 UI 中 5 项通过，云端删除用例失败，不能把该轮记为全通过。结果包：`artifacts/ios-tests/ios-20261025-090316-46696.xcresult`。

云端用例失败时导出的界面层级证明，第二次删除点击后原生 popover 仍在，尚未执行删除，不是已经收到错误后提示消失。测试此前第二次打开确认后立即点击，未等待确认项就绪；已改为限定确认 sheet、等待存在及可点击，再执行确认。为避免根据错误归因改变界面规范，撤回临时红字条试验，保留与 TXT 一致的错误弹窗。

修正后 build129 定向复验 **2/2 通过、0 skipped/failed**：云端取消/确认/失败提示与位置保留，以及完整空书签/保存/重复提示/预览返回/取消删除/确认删除。结果包：`artifacts/ios-tests/ios-20261025-091119-167.xcresult`；日志 `/private/tmp/xlib-0141-functional-ui-confirmation.log`。命令：

```sh
make test-ios IOS_TEST_ARGS='-collect-test-diagnostics never -only-testing:XLibReaderUITests/ComicFlowUITests/testComicCloudConfirmationAfterOptionsDismissesAndFailureKeepsPage -only-testing:XLibReaderUITests/ComicFlowUITests/testComicEmptyBookmarksSaveDuplicatePreviewAndConfirmedDeletion'
```

最终代码的模型行为不变，27 项结果沿用 build128；漫画 6 项 UI 的验证分两轮覆盖（build128 的其余五项及 build129 的两项，其中书签重复复验），不宣称某一轮全量 33/33。两轮都没有物理设备测量，也不代替整个客户端全量回归。

已导出并目视检查 build128/129 的设置卡片、删除确认与失败提示截图：完成/刷新使用主题强调色，破坏性操作使用红色；错误弹窗文字完整，失败后仍为第 1 / 24 页，本地位置未改变。截图是 xcresult 内对应命名附件，不作为性能测量。

测试覆盖新增的模型书签门控与重复位置、空列表/保存反馈/错误、书签临时预览与返回/取消删除/确认删除、设置面板与云端失败、缺失源文件重试/返回；同时回归漫画双向各 20 页、固实 CBR、主题/RTL/缩放/长图/旋转/恢复，以及 PDF/EPUB 的已有文档模型行为。截图保存在对应 xcresult 附件中。

首轮新增 UI 用例曾误用不存在的 XCUI `lastMatch`，修正为明确的“删除书签”确认项后编译成功；随后测试发现 popover 无取消按钮、短提示捕获时间与缺失源文件夹具阶段问题，已分别按原生外部取消、延长反馈及在进入阅读后触发缺失修正。build127 与 build128 均在未等待第二次确认的用例失败，其他五项 UI 通过；失败记录保留，不用单元通过冒充 UI 全通过。

该历史轮 `make check` 在默认发布清单与当前组件版本不一致处失败；前置敏感数据、11 路由/夹具、清理及退役检查通过，日志 `/private/tmp/xlib-0141-replan-check.log`。后续用户已授权修正开发检查入口，最新结果见 [Kindle 实施记录](0.14.1-kindle-implementation.md)；未改号或伪造 release。
