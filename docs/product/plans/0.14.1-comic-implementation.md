## 1. 已实现的公共服务子项

- 现有 v2 按原始文件 SHA-256 + fileSize 读写 CBZ/CBR 位置，不增加逐后缀端点、不上传原包、页面路径、书名、图片或书签；TXT v1 继续隔离。
- 漫画 locator 严格限定 `format: cbz/cbr`、`version: 1`、`profile: comic-order-v1`、manifestHash、pageKey、page、pageCount、y。两个哈希为小写 64hex；pageCount 为 1–10000 整数，page 为 `[0,pageCount)` 整数，y 为有限的 0–1 数值。未知字段、版本、profile 和 Kindle 拒绝。
- y 按 JSON 数字的十进制值半上取整到六位小数，覆盖 `0.5000005 → 0.500001`、极小科学记数值和近半边界；读取也使用相同规范化。漫画进度为 `(page+1)/pageCount`，不受 y 影响。PDF `(page+y)/pageCount`、EPUB 原有 spine/正文公式未改。
- 同文件先检查 format/version；漫画再检查 profile/manifestHash/pageCount。同页要求 pageKey 一致，不同页允许 pageKey 不同。冲突在时间比较之前返回 422 `VALIDATION_FAILED`，整批事务回滚，不让新时间覆盖不兼容清单。
- 兼容后沿用较新阅读时间、同时间设备公开 UUID 排序、未来五分钟调整、身份锁、幂等结果、单书删除和身份隔离规则。服务端不能判断客户端是否处于正式阅读阶段。
- 新增 `004_comic_progress.sql`，未修改已执行的 003。004 在原 document_progress 上扩展 CHECK：漫画字段类型/完整性、未知字段、profile/hash、页数/页码及规范化 y 均受约束；旧 PDF/EPUB 数据及既有权限保留。迁移入口显式补授 document_progress 的应用角色 DML 权限；owner 执行迁移，API 仍不获 DDL 权限。

对应文件：[定位与服务](../../../services/backend/src/document-progress.ts)、[004 迁移](../../../services/backend/migrations/004_comic_progress.sql)、[迁移入口](../../../services/backend/src/migrate.ts)、[OpenAPI](../../../contracts/openapi.yaml)、[API 说明](../../API.md)。

R014-12 的漫画契约/Backend 部分已有证据；R014-13 的服务端旧格式与 PostgreSQL 保留部分已有证据。两项完整客户端/跨端需求仍待各端验证，不能据此标成整项完成。

## 16. 导入、封面、真实手势与公共原生安全补齐（2026-10-24）

本节是当前记录；前文各轮计数与“尚无 NDK/等待许可/未支持固实”等历史描述不再作为最新缺口。

### 本轮实现

- **完整类型/原文验证**：TXT 从只检查开头 4 KiB 改为全文件 64 KiB 分块验证，支持 UTF-8、UTF-16LE/BE、GB18030 的跨块边界，拒绝晚出现的控制/二进制数据和尾部残缺编码，原字节不转码。PalmDB BOOKMOBI 内容明确提示 Kindle 尚未开放，不因未知后缀落入 TXT。
- **可取消与容量保护导入**：书架加载卡片提供“取消导入”，后台到期也取消同一任务；验证/发布前检查取消。复制开始及每个写入块检查空间并保留 16 MiB 余量；低容量、取消、发布失败均保留旧书/进度/书签和原文件，清理本次临时/未发布副本。容量预检是尽力保护，不能取代真实写入错误与设备磁盘耗尽验收。
- **第一页封面/图像完整性**：按自然清单第一页生成最长边 192 像素封面，串行后台解码、内存缓存 8 MiB/64 项、可清空重建；不用物理条目顺序，不产生阅读事件。JPEG EXIF 旋转后尺寸/原色、封面重建及末页损坏/后缀伪装/非支持图片必须整本拒绝都有回归。
- **实际漫画手势**：未放大时 UIScrollView 的平移等待翻页手势判定，放大后恢复原生图片平移；保留左边缘系统返回优先级。新增真实 RTL/反向翻页、放大拖图不翻页、适宽/整页、主题、长图拖动、旋转/同页重开与书签测试。开关点击控件本体并断言值，避免标签点击造成无效设置。Debug 手势诊断仅含页索引、坐标和开关状态，不含原文、账号、身份或文件名。
- **真正的原生 UB 修复**：ASan/UBSan 在合法 RAR4 stored 正例上发现上游 UnRAR 类型指针未对齐读写；改为 memcpy，并保护 LE/BE 32/64 位访问，没有关闭或抑制 sanitizer。七个未对齐偏移回归和四原包固定种子 1024 例截断/变异通过，980 例被拒绝；其余有效变异允许成功。每例五秒/输出预算、合法原包、取消/恢复必须通过。这是有界变异回归，不是覆盖引导 fuzzing 或完整安全审计；macOS 不启用 LSan，地址/对齐/UB 检查仍开启。
- **Android 可消费公共构建**：CMake 增加同一平台无关 `xlib::comic` 配对门面，公共 min23 兼容头及实际 NDK API 检查，不依赖 Android 私有复制。三 ABI API23 编译/配对链接与探针 PT_LOAD≥16KiB 已通过，API22 必须拒绝。没有修改 `apps/android`；最终 JNI/APK/设备和跨端签核继续由客户端/联合验收承担。
- **后端测试稳定性**：共享 locator 向量原先为每条校验重复启动 Ruby，完整并行检查曾超过默认五秒。现一次加载并审计 OpenAPI 后校验同一组全部正反例；未删案例、未延长超时、未放宽线上 schema。复跑实际耗时约 349 ms，完整 PostgreSQL 回归通过。
