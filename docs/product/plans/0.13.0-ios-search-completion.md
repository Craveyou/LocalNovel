# iOS 搜索边界补齐记录

日期：2026-10-23。依据 [功能完成清单 I01/I02](0.13.0-client-completion-review.md)、[CAP-SEARCH](../capabilities/search.md)、[iOS 客户端](../clients/ios.md) 与 [能力矩阵](../matrix/capability-matrix.md)。本轮只修改 iOS 与文档，不继承 Android 平台专属交互。

## 完成范围

- I01：PDF 默认搜索从当前页内视觉位置起搜。以未裁剪原框和页面旋转方向计算 PDFKit 文本 offset；与顶边相交的文字仍可搜索，顶边之前的文字只在用户主动回绕后出现。页首为 0，页尾为正文末端，无文本层不新增 OCR。
- 原始框按访问页惰性缓存，只保存 CGRect，不保留额外 PDFPage 对象。裁边、缩放和视口宽度不改变搜索坐标；不写原文件、正式位置或阅读时间。
- 查询建立时固定原起点；加载下一批、打开临时搜索预览、继续加载和回绕均使用同一游标。200 条是每批大小，不是总上限。
- I02：仅当原起点之前有范围、已搜完后半段且尚未回绕时显示回绕按钮。书首起搜完成直接显示“已完成一轮搜索”；模型层也拒绝无效或重复回绕。
- SwiftUI 只读取模型提供的回绕条件，不在界面重复维护搜索状态；沿用已有可取消搜索任务。TXT 搜索器未修改。

代码入口：[模型](../../../apps/ios/XLibReader/Documents/DocumentReaderModel.swift)、[搜索面板与 PDF 原始框](../../../apps/ios/XLibReader/Documents/DocumentReaderView.swift)。PDF 字符矩形使用 Apple 定义的页坐标系，见 [PDFPage.characterBounds(at:)](https://developer.apple.com/documentation/pdfkit/pdfpage/characterbounds(at:))。

## 自动化覆盖

新增三个文档单元测试：

1. 两段 PDF 正文，上段 1 次、下段 250 次命中；从下半页搜索，先 200 再 50 条，主动回绕后才出现上段 1 条；临时预览不重置原起点，不改正式进度/时间。改从书首搜索后仍可续查 251 条，但不提供回绕。
2. 用 PDFView 的实际坐标转换作为参照，覆盖 0/90/180/270°、原页/裁边、0.5/2 倍缩放、页首/页中/页尾位置。
3. EPUB 非书首起搜可主动回绕；书首起搜直接结束，无效回绕无副作用，正式进度与时间不变。

新增真实界面用例 `testDocumentSearchWrapOnlyWhenOriginalStartHasUnsearchedPrefix`：PDF 第 2 页、EPUB 第 2 章分别搜索无命中词，主动回绕一次后结束；再从书首搜索，不显示回绕；返回阅读位置不变。并回归既有 PDF 搜索/书签/重开、EPUB 预览/重排和 PDF 全局裁边流程。
