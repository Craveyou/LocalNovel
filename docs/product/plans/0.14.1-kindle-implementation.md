日期：2026-10-25。工作目录：`/Users/iclawtse/workspace/projects/xlib`，现有 local main 工作区；所有修改未提交，不创建分支、不 push、不发布或部署。Android 的现有修改不由本任务覆盖。设备测试按 Decision 0020 后置。

## 已实现

- 共享离线解析核心 `packages/kindle-core`：同一 JavaScript 源用于 Node/Apple JavaScriptCore 与 Android 宿主。固定 foliate-js commit `78914aef4466eb960965702401634c2cb348e9b1` 的非 DOM MOBI 解码部分，MIT；原始文件 SHA-256、适配和分发说明见包 README。没有链接候选 libmobi/LGPL、外部命令或云端转换，不引入第三方阅读工具栏。
- 六个完整可阅读 CC0 原包：未压缩 MOBI6、PalmDOC/AZW、HUFF/CDIC、KF8/AZW3、混合和长正文；同文件可改名，模式由内容确定。每包保存原始 hash/size、规范正文、textHash、章节/目录/源映射输出。
- iOS 导入实际解析验证后才原子发布，DRM/不支持/损坏不误入 TXT，取消/低空间沿用原导入原子性。解析器在后台独占 VM，随机读取，图片离线加载和受控解码，不修改原书。
- Kindle 使用 iOS TXT 风格的玻璃工具栏、主题/锁屏、菜单、设置卡片、书签反馈及双滚轮“前往”；复用安全 WKWebView 文字/图片渲染，不借用 EPUB locator。35/20/45 点击区，左右轻触滚动一屏或进入相邻单元，中间显隐菜单；原生选词/拖选/锚点微调及复制/取消，复制不暴露图片占位。
- 目录/内部链接、字号/字体/行距/主题/宽度重排；正文搜索 2–32 字素簇、大小写不敏感、不重叠、200 条续查/主动回绕；临时预览不改正式位置，书签去重/单条删除、关闭重开恢复；缺失原书保留已有坐标。
- `kindle-text-v1` 参考算法与双向映射见 [规范](../../architecture/kindle-text-v1.md)。Node/JSC/Android 六原包相同正文/hash/映射，两端实际 DOM 与选区已有验证；真正双端五阶段接续也已通过，见 [联合记录](0.14.1-kindle-cross-client-validation.md)。不把模拟器结果当作完整设备/G2/G3 出口。
- AppleShared 严格 Kindle 编解码/字素边界/本书验证；iOS SQLite v5 typed 存储无损重建 v3/v4 表；后端 OpenAPI / docs/API / Zod 与 PostgreSQL **005**（不改 003/004），内容身份不符先于时间裁决拒绝，旧协议/旧格式语义保持。
- 继续复用正式阅读会话的 20 秒调度、阅读前比较、活动书上传、离线保护和单书删除暂停；不增加全书库补传或独立后台定时器。
- Kindle 封面优先采用内置声明封面，否则首张有效图片；后台生成最长边 192 像素缩略图，8 MiB / 64 项可重建缓存。清空/重建不改正式位置、阅读时间或原文件。图片支持 PNG/JPEG/GIF，原图验证与缩略解码走有界 ImageIO。
