# 0.13 iOS 真机自动验证

日期：2026-10-23。设备：有线连接的 iPhone 15 Pro Max，iOS 26.5.2。使用项目现有开发团队，用户明确批准自动配置测试签名；未发布或部署。客户端版本名保持 0.12.0。自动测试采用独立临时数据库和自建文档，不删除用户书库。

## 已发现并修复

- Xcode 27 的真机测试构建将共享 Swift 包作为动态框架嵌入，应用缺少 `@executable_path/Frameworks` 加载路径，启动时报 `Library not loaded`。已为 Debug/Release 增加加载路径；随后真机单元测试启动并执行成功。
- 既有大文档测试只允许模拟器，且主机绝对样本路径不能在手机沙箱使用。增加显式真机 opt-in 与独立缓存目录入口，运行器自动传输相同六类样本。Release 测量使用专门的 `XLIB_DOCUMENT_DEVICE_PERFORMANCE` 编译标记暴露数据库测试清理钩子，不开启 Debug 编译。
- 清理产品总览、PDF/EPUB/阅读能力、多格式方案和 iOS 存储说明中的过期实现状态。TXT v1 与文档 v2 保持隔离，SQLite 当前为 v3，legacy 回退已移除。
- 真机 UI 运行器在后台无法访问通用剪贴板，原 `changeCount` 断言总为零。改为仅在 Debug 且使用 UUID 隔离测试书库时，由前台应用提供系统剪贴板代际，不读取或暴露内容。TXT 锚点拖动测试改为使用实际渲染坐标，避免按模拟器宽度写死的位置在真机上点空；生产环境不包含这些测试探针。

## 已执行的普通测试

Debug build 72 在真机执行普通单元套件：**102 项通过、7 项显式 opt-in 跳过、0 失败**。首次构建因测试运行器缺少描述文件失败；获用户明确批准配置签名后，启动暴露上述框架路径问题。修复后单元测试通过。这些失败记录保留，不计为成功运行。

最终 Debug build 77 再次执行普通单元套件：**102 项通过、8 项 opt-in 跳过、0 失败**。八项为六类文档性能、一项连续切书和一项真实服务集成；性能项在下述独立 Release 运行中实际执行，不把跳过计作通过。

根 `make check` 两次通过，最终 iOS 检查构建为 0.12.0 build 78（相对真机 build 77 仅构建号变化）。该检查包含契约、安全、后端常规测试、共享 Swift、Android 单元/lint 与 iOS Simulator 构建；不表示执行了生产部署或本轮 PostgreSQL/Alpha 专项。

最终 Debug build 77 的 **22 个不同 UI 用例均有通过记录**：选文/剪贴板修正后的三项专门回归通过；其余 19 项批次中 17 项通过，书签点击被系统通知横幅干扰，一次设备配置页侧滑未完成。保留该失败批次，随后不改代码单独复核两项，均通过。因此属于同一构建分批完成覆盖，不声称一次完整批次零失败。

覆盖书架手势和确认删除、同步页面结构/设备入口/邮箱自动保存、设置与原生侧滑、TXT 书签判重及删除、搜索临时阅读、进度双滚轮，以及 PDF 密码错误重试/取消/重开、导航/搜索/书签、快速滚动保存恢复、PDF/EPUB/TXT 选文、复制时机与正式进度隔离。界面测试使用隔离配置/模拟 API，不将其作为本轮真实云端接续验收。已导出并检查 TXT 双锚点与复制菜单、深色进度选择截图；图像证据来自测试书籍，不读取用户书库。

## PDF 裁边追加验证（同日）

按用户最新要求，裁边为所有 PDF 共用的全局内存状态，不按书保存、不写数据库，重启应用后默认关闭。SwiftUI 原生面板提供启用开关、左右各 0–30% 的独立滑块与恢复原页；使用会话内 PDF cropBox 和宽度适配，不写回文件。设置状态按共享设置对象注入，不使用全局静态单例。

Debug build 85 真机执行 **12 项文档单元测试和 2 项 UI 测试，14 项全部通过、无跳过**。覆盖旋转/边距限幅、全局跨书状态、不持久化、原文件字节与正式进度不变、窗口宽度变化、搜索预览后居中、菜单调整、切换另一加密 PDF 后共用设置、恢复原页，以及原有 PDF 导航/搜索/书签/重开。最终 `make check` 通过，当前 0.12.0 build 86；相对真机包仅构建号前进。

初次 UI 自动化点击了原生开关行中部而非右侧开关，未启用裁边；改为点击实际开关并等待状态。后续截图检查发现 PDFDestination 使放大的页面横向偏移，已修正 x 居中，并追加左右边缘位置断言及缩放/搜索后居中验证。最终截图已确认裁框填满阅读宽度。裁边为手动操作，测试采用左 15%/右 10%，会遮挡样本落在该范围内的文字；不宣称自动识别正文或保证任意数值不裁字，用户可减小边距或恢复原页。

最终证据：`/private/tmp/xlib-ios-pdf-crop-final-tests.xcresult`、同名 `.log`；截图及 manifest：`/private/tmp/xlib-ios-pdf-crop-final-evidence/`；根检查：`/private/tmp/xlib-ios-pdf-crop-final-check.log`。此前按书保存的中间实现已移除，不作为交付行为；早期测试结果不替代上述最终全局状态验证。需求与边界见 [iOS 裁边交互](../clients/ios-interaction-requirements.md#pdf-阅读显示裁边2026-10-23-新增)。

## 六类大文档 Release 测量

Release build 74，每类三轮，共 **18 轮、180 次导航**。沿用原性能报告的相同六类自建样本和 manifest；每轮验证导入、渲染就绪、十次定位、实际 EPUB 文字可见、分批搜索、无命中全书搜索、取消/替换、关闭重开及正式进度/时间隔离。计时场景顺序运行，未清系统缓存；结果不是冷启动或首像素时间。

| 样本 | 导入中位 ms | 打开中位 ms | 导航中位 / 最大 ms | 全书无命中中位 ms | 应用采样峰值 MiB |
|---|---:|---:|---:|---:|---:|
| pdf-small | 3.9 | 12.9 | 11.1 / 11.2 | 10.9 | 388.6 |

| pdf-images | 68.0 | 38.4 | 11.1 / 11.3 | 10.3 | 305.3 |

| epub-long-chapter | 913.1 | 2301.2 | 11.2 / 1695.8 | 43.0 | 77.4 |

导航以定位确认完成为终点，约 10 ms 轮询粒度；小数字不能视为每帧耗时。两章缓存命中使超长章导航中位数较低，但首次导航仍有约 1.70 s 等待，首次打开约 2.30 s。应用内存为 50 ms 采样 physical footprint，不含独立 WebKit/GPU 占用，不能作为完整设备峰值内存。

三类 PDF 的三轮关闭检查中，原打开和重开的 `PDFDocument` 弱引用均在五秒上限内释放；千页样本为约 0.41–1.05 s。千页 PDF 关闭后应用占用约 176–222 MiB，采样峰值最高约 512 MiB；框架对象释放不等于所有系统缓存归还，也不能据此宣称全部内存风险已解决。

## 连续切书与系统采集

Release build 76 追加 **30 次交替打开千页 PDF 和超长章 EPUB**，约 129.1 秒完成，断言实际定位、数据库位置及关闭后的章节 WebView 释放均通过。每次使用新的阅读模型和窗口，在同一进程保留书库后交替开关文档；关闭后应用采样占用首轮 97.0 MiB、末轮 73.3 MiB、期间最高 165.4 MiB。此项覆盖连续切书，不等于数小时日常使用或完整系统内存验收。

尝试用 Instruments Activity Monitor 采集 120 秒进程内存；采样到时后在保存阶段停滞，导出返回 `Document Missing Template Error`。结束本次停滞的采集进程并保留部分 `.trace`，未将其视为有效总内存证据，未用应用 footprint 代替 WebKit/GPU 总量。

完成 UI 自动化系统认证后，追加 30 秒 Activity Monitor 记录成功保存并导出。采集窗口为小样本 UI 回归，应用进程峰值约 118.1 MiB；窗口内观察到的 WebContent 峰值约 61.9 MiB、WebKit GPU 进程约 47.6 MiB。表中 responsible process 均指向 launchd，不能可靠将窗口内所有 WebKit 进程唯一归属本应用，故不累加为“应用总峰值”。GPU 进程 footprint 也不等于所有驱动/纹理显存；该诊断记录不代替大文档全链路内存验收。有效记录：`/private/tmp/xlib-ios-ui-memory-20261023.trace`，TOC 和进程表导出为同名前缀的 `-toc.xml`、`-processes.xml`。

## 仍需区分的验收范围

真机 UI 自动化需 iOS 在手机上进行一次系统密码认证，普通解锁不等于已启用 UI 自动化。最初启动在该认证处超时；用户完成本机认证后，自动操作已正常运行。认证超时记录不计为 UI 通过，系统密码未写入测试或交给运行器。

本报告的自建扫描/文本/密码和长章节样本不代表所有复杂真实文件、更多加密算法、低端 iPhone 或长期日常使用。没有预先批准的数值性能预算，不将测量结果改写成性能预算验收通过。版本升级及最终 Alpha/发布验收仍需按 0.13 计划执行。
