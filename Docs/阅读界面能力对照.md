# 阅读界面能力对照（相对千阅 2.8.6）

本文件记录「小说」分区已移植的能力与仍未做的部分，供后续接手时对齐。
只作用于小说；漫画 / 整理 / 短剧保持原样。

## 已做（2.11.1 → 2.12.1）

| 能力 | 说明 | 关键文件 |
|---|---|---|
| 排版全套 | 字号 / 字体 / 字重 / 行距 / 段距 / 字距 / 左右边距 / 对齐 / 首行缩进 / 繁简 | `Core/ReaderStyle.swift`、`Core/TextPaginator.swift` |
| 章节标题样式 | 字号比例或固定值、字重、斜体、上下间距、下划线、分两行；标题排进正文第一页 | `TextPaginator.titleAttributed` |
| 页眉页脚 | 内容（章节名/书名、页码/百分比）、开关、四向间距、颜色随主题 | `Views/PagedReaderView.swift` |
| 主题 | 6 套内置 + 自定义（6 色 + 背景图 + 夜间标记）、阅读亮度、常亮 | `Core/ReaderStyle.swift`、`Views/ThemeEditorView.swift` |
| 翻页引擎 | 上下滚动 / 仿真 / 平移 / 覆盖 / 上下翻页 / 无动画，六档共用一套分页与锚点 | `Views/PagedReaderView.swift` |
| 菜单栏 | 顶部条（返回 + 书名 + 净化）、底部条（上一章 / 进度滑杆 / 下一章 + 五工具）、右侧浮动圆钮 | `Views/ReaderChromeBars.swift` |
| 目录面板 | 从下方浮出，三 Tab：目录 / 书签 / 笔记；章节名搜索 / 正文搜索、正序倒序、定位当前章 | `Views/ReaderCatalogView.swift` |
| 书签 / 笔记 | 增删、列表、**精确跳段**、导出 txt | `Core/ReaderAnnotations.swift` |
| 手势 | 三块点击区可配、音量键翻页、启动直进上次书 | `Core/VolumeKeyPager.swift` |
| 净化 | 正则替换规则 + 样本预览、流水线缓存（净化 → 繁简） | `Core/PurifyEngine.swift`、`Views/PurifyManagerView.swift` |
| 字体导入 | ttf/otf 导入沙盒并注册，复用全工程唯一 fileImporter | `Core/ReaderFontLibrary.swift` |
| 重新分章 | 按书自定义分章正则 + 前 2000 行样本预览 + 一键恢复自动分章；重切后缓存与锚点整批重建 | `Core/ChapterSplitter.swift`、`Views/ChapterRuleSheet.swift`、`Core/LibraryStore.swift` |
| 全书正文搜索 | 目录搜索框加「正文」开关；后台分章扫描 + 进度 + 可取消、命中上限 500、关键词高亮、点结果精确跳段 | `Core/BookSearch.swift`、`Views/ReaderCatalogView.swift` |
