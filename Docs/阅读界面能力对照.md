## 2.12.2 修掉的 bug（详见 .workbuddy/artifacts/bug-report-2.12.1.md）

| 严重度 | 问题 | 修法 |
|---|---|---|
| 高 | 覆盖翻页模式下点按钮 / 音量键不翻页，页码却前移 | 引擎自己记 `displayedIndex` 判断「是否已在看这页」，不再用 `currentIndex` 早退；过渡加序号作废旧动画回调 |
| 高 | NAS 图片缓存写盘目标写成目录 → 永远不缓存 | 写盘目标改为文件，淘汰仍扫目录 |
| 高 | 滚动时加书签记到 0.6 秒前的段落 | `anchor(for:)` 先读内存里未落盘的 `pendingAnchors`，并与 flush 互斥 |
| 高 | 重分章后书签 / 笔记变死链、已删章节复活 | 失效条目在列表里标记「章节已失效」+ 可清理；重分章时清掉失配的隐藏记录 |
| 高 | 点当前章的书签无反应，跳转请求还残留 | 同章跳段走页面命令就地执行；跨章 `restoreParagraph` 优先读 `pendingJump` |
| 高 | 手选过编码的书重新分章静默失效 | 重切与样本预览都用 `preferredEncoding(for:)` |
| 中 | 扫描中删章 / 删书的提示丢失 | 挂起的 rescan 连同 completion 一起补跑 |
| 中 | 删书不清书签笔记 | `AnnotationStore.removeAll(in:)` |
| 中 | 视频播完按钮卡在「暂停」、再进不续播 | 监听 `didPlayToEndTime`，播完清进度，再点从头播；远端也按进度 seek |
| 中 | 同章多视频共用进度 key 互相串台 | 进度 key 改成「章 + 媒体 URL」 |
| 中 | 改净化规则后分页不重建（显示旧正文） | 指纹加入 `contentStamp`（净化规则 + 繁简） |
| 中 | 覆盖导入回滚可能删掉原书；进程被杀原书变隐藏备份 | 回滚顺序改为「半成品先挪开 → 旧副本移回」；启动时还原 `.ln-backup-*` |
| 中 | 小说文件夹导入同名文件静默互相覆盖 | 本批内重名自动改名（`(2)`），提示改名数量 |
| 中 | NAS 目录平铺多个 txt 只有第一本可读 | 每个文件各算一章（`kind: .text`） |
| 中 | 远端文件缓存无上限 | 512 MB 上限 + 最久未修改淘汰 |
| 中 | 主动取消被当成「连不上」，作废已探测连接 | 取消单独映射为 `CancellationError` |
| 中 | 会话 60s 超时截断 PDF 的 120s 请求 | `timeoutIntervalForResource` 提到 180s |
| 中 | 漫画页首解失败后永久空白 | 失败时允许同一 URL 重试 |
