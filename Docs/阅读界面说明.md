# 阅读界面说明（2.11+）

这一版把小说的入口和阅读中的操作 concentrates 到一处：**点书直接读，点屏幕中间出菜单**。

## 1. 小说：打开书直接阅读

- **小说**点书直接进正文，没有「章节目录」中间页。
- 打开位置：
  - 之前读过 → 从**上次读到的那一章、那个位置**续读；
  - 第一次打开 → 从第一章开始。
- 点书后会先出现「正在准备《书名》」，然后才进正文：
  - 第一次打开：后台按「第X章」把整本切好、把正文读进内存，再进阅读页；
  - 之后打开：正文已在内存，基本秒进。
  - 之前版本是「先拿整本当一章进阅读页」再切章，等于在主线程排版整本书，点一下会卡好几秒；现在准备全在后台，界面只等一小会儿，不会僵住。
- **漫画 / 短剧 / 整理保留章节列表**：点书先看到「第1话 / 第1集…」这一栏，点某一话才进正文。
  - 点书时不会再被弹回书库首页：书库第一栏停在哪一层（分区 / 系列）由主界面统一记着，
    布局从两栏切到三栏时不会把这一层的状态清掉。
  - 从章节列表进去的那一章，会接着上次读到的位置续读；**点目录里的某一章则一定从这一章开头开始**。

想换章不用退出：用下面控制菜单里的「目录」。目录面板里长按某一章可以删除，
右上角「管理」进入多选批量删除（整本切出来的章节与只读目录只会隐藏，可在「设置 → 书库」恢复）。

**换章位置怎么定**（这一条曾经反复出 bug，现在的规则是「谁说就听谁的」）：
- 在目录里点某一章 → 从这一章的**第一段**开始；
- 点书签 / 笔记 / 正文搜索结果 → 落到记录的那一段；
- 拖进度条 → 落到「章 + 章内比例」换算出来的那一段；
- 点书 / 退出再进 / 章末续章 → 按这一章上次读到的位置续读。
上层把「这一章从第几段开始」作为明确参数交给阅读器，阅读器不再自己去猜旧记录，
所以不会再出现「点了第 20 章却停在第 20 章最后几页」。

翻页引擎也换成了千阅那套模型：**页码是状态，不是从滚动偏移算出来的**。
平移 / 上下用系统分页器（`UIPageViewController(.scroll)`），跟手横移与松手吸附都由它给；
跳章、跳书签只是把目标页 `setViewControllers` 装上去，落哪一页就是哪一页。
旧版自己拿 `UIScrollView` 反推 `contentOffset`，切章首帧 `contentSize` 一变就被夹到末尾，
这才是「一点章节就跳到最后一页」的真正原因。

## 1.1 读完一章 = 翻到下一章（章末不再有按钮）

章末那颗「下一章」卡片去掉了。读完本章最后一页，**再往后翻一下就是下一章**：

| 阅读方式 | 怎么进下一章 |
|---|---|
| 平移翻页 | 在末页继续往左划（系统分页器已经顶住时，再划一下） |
| 仿真翻页 | 在末页继续左滑 |
| 点击翻页 | 末页点屏幕右侧 |
| 上下滚动 | 滚到底后继续往上拉一截 |

- 下一章从**章首**开始；本章位置仍记着，回到这一章会接着上次读的地方。
- 整本的最后一章没有下一章，章末留一行「已是最后一章」，翻到头就停住，不会循环。
- 快速连翻甩到末页那一下不算「要继续」：要先把末页看完，再单独翻一次才换章。
- 漫画 / 整理 / 短剧不受影响：它们本来就是连排到底 + 点章末的「下一章 / 下一集」。

## 2. 屏幕中间单击 → 控制菜单

阅读时**单击屏幕中间区域**（横向中间约 44%）弹出控制菜单；再点一次中间、或点菜单外的半透明区域收起。

> 左右两侧 28% 仍保留原来的翻页 / 滚动手势，不会误触菜单。
> 图片点开大图等子视图优先响应，点它们不会弹菜单。

控制菜单里可以调整：

| 项 | 说明 |
|---|---|
| **字号** | − / + 逐号调整，范围 14–30 |
| **行距** | − / + 逐档调整，范围 4–24 |
| **翻页方式** | 平移 / 仿真 / 上下翻页 / 覆盖 / 无动画（小说五档；另两类固定滚动） |
| **外观** | 跟随系统 / 浅色 / 深色 |
| **文本编码** | 仅读文字的章节有；乱码时手动切，按书记忆 |
| **目录** | 弹出本书章节列表，点章跳转，当前章打勾 |
| **退出阅读** | 回到书库 |

字号 / 行距 / 翻页 / 外观的改动**即时生效**，直接写在阅读偏好里，下次打开仍然保持。设置页里也有同样的开关，两处互通。

## 3. 目录弹层

从控制菜单点「目录」：

- 列出本书全部章节（单文件切出来的虚拟章也按顺序列出；切章前的占位章不显示）；
- 当前正在读的章节右侧有勾；
- 点某一章 → 从**该章开头**开始读，并记住这是「最近读的章」；
- 顶部「完成」或点选后可关闭。

## 4. 常见问题

**Q：点书没有直接进正文，还是看到目录？**
A：只有「小说」分区是选书即读。漫画 / 整理 / 短剧本来就要选章，属正常。

**Q：控制菜单弹不出来？**
A：要点**横向中间**区域；左右两侧是翻页区。滚动 / 漫画模式下，落在大图或按钮上的点击会优先执行看大图 / 按钮动作。

**Q：换章后位置不对？**
A：从目录点章是从章首开始（有意设计）；自动续读时才恢复段落位置。
