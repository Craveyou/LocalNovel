# 漫画目录结构说明

本地小说阅读器只认目录结构，不靠文件名猜内容。把漫画放进
「文件」App → 我的 iPhone → 本地小说 → **漫画/** 即可。

---

## 一、最核心的三条

| 层级 | 判定为 | 说明 |
|---|---|---|
| 漫画名文件夹 | **一部漫画** | 书库列表里的一本，标题就是文件夹名 |
| 中间文件夹 | **卷名** | 「第1部」「单行本」这类；多层用「 · 」连接 |
| 直接放着图片的文件夹 | **一话** | 只看这一层自己的图片，不含子文件夹里的 |
| 目录下的每个 pdf | **一话** | 一个 pdf 就是一话，按页渲染 |

> 只有「漫画名」这一层是必须的，中间可以没有「部」，直接是「话」。

---

## 二、支持的几种形态

### 1. 漫画名 → 部 → 话 → 图片（最常见的单行本）

```
漫画/
└─ 星海旅人/
   ├─ 第1部/
   │  ├─ 第1话/
   │  │     001.jpg   002.jpg   003.jpg …
   │  └─ 第2话/
   │        001.jpg …
   └─ 第2部/
      └─ 第1话/
```
列表里显示：`第1部 · 第1话`、`第1部 · 第2话`、`第2部 · 第1话`。

### 2. 漫画名 → 话 → 图片（没有「部」）

```
漫画/
└─ 深海食堂/
   ├─ 第01话/  001.jpg …
   ├─ 第02话/  001.jpg …
   └─ 第03话/  001.jpg …
```
列表里就是 `第01话`、`第02话`、`第03话`。

### 3. pdf 单话，或与图片话混排

```
漫画/
└─ 星海旅人/
   ├─ 第1部/第1话/001.jpg …
   └─ 第5话.pdf
```
一个 pdf = 一话，按页懒渲染（滑到哪页才生成哪页，不占内存）。
图片话和 pdf 话在同一部里按名称自然排序混排。

### 4. 更深一层（单行本 / 卷）

```
漫画/
└─ 短篇合集/
   └─ 单行本/
      └─ 第3话/  1.png 2.png
```
`单行本` 记为卷名，显示为 `单行本 · 第3话`。最多支持到第 5 层。

### 5. 漫画名这一层直接放散图

```
漫画/
└─ 单张合集/
      a.jpg   b.jpg   c.jpg
```
整部只有一话，那一话的标题就是漫画名。

### 6. 「漫画」根目录直接放图片（没有漫画名文件夹）

整个「漫画」分区当作一部，标题是「漫画」。只建议临时看图时这么放。

---

## 三、排序与格式

| 项目 | 规则 |
|---|---|
| 话的排序 | 自然排序：`第2话` 在 `第10话` 之前；`1.jpg → 2.jpg → 10.jpg` |
| 图片格式 | jpg / jpeg / png / webp / heic / heif / bmp / tiff / gif / apng |
| pdf | 每个 pdf 一话；扫描版没有文字层也能正常显示（走按页渲染） |
| 动图 | gif / apng 按帧播放，可见才播、离屏暂停 |

---

## 四、会被忽略的文件

- 隐藏文件（`.` 开头）、`Thumbs.db`、`desktop.ini`
- 根目录的 `放书说明.txt`（App 自动生成，用来让「文件」App 显示本目录）
- 不认识的扩展名（如 `.zip`、`.txt`、`.json`）；阅读页底部会提示「已忽略 N 个未识别文件」

---

## 五、识别不出来时自查

| 现象 | 原因 | 怎么改 |
|---|---|---|
| 整部漫画没出现在书库 | 放成了 `漫画/xxx.jpg` 散图但根目录已有别的漫画文件夹 | 建一个漫画名文件夹，把图放进去 |
| 只识别出 1 话 | 图片放在了漫画名层，而不是「话」文件夹里 | 每话建一个文件夹再放图 |
| 顺序乱 | 文件名不是统一序号（如 `a.jpg`、`封面.jpg`） | 用 `001.jpg`、`002.jpg` 这类纯数字名 |
| 一话里少了图 | 图片放在话文件夹的子文件夹里 | 图片直接放在话文件夹根下 |
| pdf 显示成空白 | pdf 是加密/损坏文件 | 换一份或转成图片 |

---

## 六、在 App 里查这份说明

**设置 → 结构说明 → 漫画 / 小说 / 整理 的目录结构**。
小说、整理两个分区的规则也在同一页，改目录结构后回到 App 会自动重新识别，不需要手动刷新。
