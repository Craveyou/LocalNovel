# 翻页模式说明（2.10+）

小说分区有三档阅读方式，都在「设置 → 阅读方式（仅小说）」里切换，改动即时生效、不影响阅读位置。

| 模式 | 手感 | 适用 |
|---|---|---|
| **滑动翻页**（默认） | 整页跟手横移，页边有纸张叠压的阴影，松手按位移 / 速度吸附到上一页或下一页；点屏幕左右边缘也能翻 | 与系统「图书」一致的日常阅读 |
| **仿真翻页** | `UIPageViewController.pageCurl`，纸张卷起的立体动画 | 喜欢拟物效果 |
| **上下滚动** | 连续长页，段落之间按行距衔接，无分页 | 快速通读、图文混排章节 |

「整理」是图文混排、「漫画 / 短剧剧照」是满宽连排，两者始终上下滚动，不受这一项影响。

## 滑动翻页怎么实现的

不用第三方库，也没有照搬任何现成实现，全部基于 UIKit 公开组件：

- **容器**：`UIScrollView` + `isPagingEnabled`，`contentSize = 页数 × 页宽`。
  滚动位置天然就是「第几页 × 页宽」，跟手、带橡皮筋回弹、松手自动吸附，
  这些都是系统滚动视图自带的行为，不需要自己写速度预测。
- **页面窗口化**：只常驻当前页前后各一页（`SlidePageController.load(around:)`）。
  整章几百页全部建出来会吃掉几百 MB；被淘汰的页在滚回来时重建，
  文字页共用同一份 `NSAttributedString`，重建只花几百微秒。
- **页边阴影**：每页左右各一条 12pt 的 `CAGradientLayer`（黑 16% → 透明），
  模拟相邻纸张叠压的暗边；`layoutSubviews` 里跟随尺寸重排。
- **点击翻页**：左右各 28% 的区域；中间 44% 单击弹出阅读控制菜单（见 `Docs/阅读界面说明.md`）。
- **页码**：底部居中，拖动过程中按滚动偏移实时更新，松手后再校准。

## 两种分页引擎共用同一套底层

滑动与卷曲都继承 `PagedBaseController`：

```
PagedBaseController          分页（CoreText）、页码、点击、锚点、页面构建
├── CurlPageController       UIPageViewController(.pageCurl)
└── SlidePageController      UIScrollView 分页 + 页边阴影
```

因此在两种模式之间切换不会丢位置：阅读记忆始终是段落锚点 `blk-pN`，
与滚动模式互通。

## 定位规则（为什么要这么写）

分页阅读器的位置恢复有两个历史坑，现在都由规则挡住：

1. **首帧尺寸不稳定**：`UIViewControllerRepresentable` 第一次布局拿到的
   `bounds` 可能还不是最终尺寸，重建分页时若用「当前页」反推段落，
   会把刚恢复的位置挤到第 1 页。
   现在只要用户还没翻页，每次重建都用传入的记忆段落（`didNavigate == false`）。
2. **记忆段落越界**：章节重新切分 / 换源后旧锚点可能超出本章段落数。
   越界值以前会命中「最后一个起始段落 ≤ 目标的页」，也就是最后一页。
   现在先用 `clampedParagraph` 收敛到本章范围内。

另外，**在目录里主动点某一章会从这一章开头开始**（与系统图书行为一致），
只有「继续阅读 / 上次读到哪一章」的自动恢复才回到上次的段落。

## 关于上传的 Apple Books ipa

对 `Apple Books_8.18.ipa.zip` 的静态检查结果：

| 项 | 结果 |
|---|---|
| Bundle ID / 版本 | `com.apple.iBooks` / 8.18 (15) |
| 最低系统 | iOS 10.0 |
| 主二进制 | 71 KB，`LC_ENCRYPTION_INFO cryptid = 0` |
| Frameworks / PlugIns | 无（只有 `Watch/` 里的手表扩展） |
| 资源 | `Assets.car`、图标、`Main.storyboardc`（空壳界面） |

结论：这是系统 App 的**外壳**，翻页逻辑在系统分区的私有框架里
（`/System/Library/PrivateFrameworks`），不在 ipa 内，包中没有可参考的
翻页代码或参数。所以本次没有从该包提取任何代码 / 资源，
滑动与卷曲两套效果是按可观察的交互特征，用公开 API 自己实现的。

## 已知限制

- 上下滚动仍是「章内连续」，翻到章末显示「下一章」，不会像图书那样整本无缝续接。
- 滑动翻页没有做「纸张纹理 / 弯曲」的 3D 变形，只有位移与阴影；
  需要更强拟物效果请切「仿真翻页」。
- 横竖屏切换、分栏宽度变化时会按当前页重新分页并跳回该页，页码总数会变。
