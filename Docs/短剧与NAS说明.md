# 短剧 / NAS 使用说明

## 一、底部分三页

书库 · NAS · 设置（设置固定在最右）。打开 App 默认停在书库。

> iPhone 上标签栏在底部；iPad 上按系统规范显示在顶部，顺序一致。
> 阅读器右上角的齿轮仍然可以直接弹出设置，不用退回标签页。

## 二、短剧（书库与 NAS 都有）

```
短剧/
├─ 逆光而行/              ← 剧名文件夹 = 一部
│  ├─ 剧照/               ← 剧照包：图片
│  │     001.jpg 002.jpg …
│  └─ 视频/               ← 视频包：每集一个文件
│        第01集.mp4
│        第02集.mp4
├─ 只有视频的一部/         ← 没有剧照也能识别
│  └─ 全集.mp4
└─ 散装短片.mp4            ← 短剧根下直接放视频 = 一部单片
```

进入一部剧后：

| 位置 | 表现 |
|---|---|
| 剧照 | 单独一段，点进去按**漫画方式满宽连排**，点图看大图（可捏合放大、左右翻、下滑关闭） |
| 视频 | 单独一段，每集一行，右侧显示 **大小 · 时长**（128.4 MB · 12:36） |
| 播放 | 与「整理」里的视频完全一致：内联播放 → 右上角全屏 → 全屏里右上角**旋转画面** → **长按画面临时倍速**，松手还原 |
| 画面比例 | 跟随视频本身（竖屏短剧按 9:16 竖着显示），不再被硬压成 16:9 |

时长是滚动到该行才读的（本地读文件头，NAS 上带认证头读），读到就缓存，不会一进页面就发一堆请求。

**格式**：mp4 / mov / m4v 由系统直接解码；mkv / avi / wmv / flv / ts / rmvb 等也会被认成「一集」
（不会再显示「不支持的格式」），能否播放取决于文件里的编码——AVPlayer 只认 H.264 / HEVC /
VP9 等常见编码，遇到不支持的编码建议先转成 mp4（H.264）。剧照支持 jpg / png / webp / heic /
bmp / tiff / gif。

## 三、NAS（飞牛）

### 1. 飞牛侧准备

1. 控制面板 → 文件共享 → **WebDAV** 开启（默认端口 5005 http / 5006 https）；
2. 给账号读写权限，记下共享路径（默认就是共享目录名）；
3. 外网访问：DDNS 或端口映射，建议外网走 https。

> **SMB 说明**：iOS 没有给 App 的 SMB 客户端接口，本项目不硬做 SMB 协议栈。
> 要用 SMB 就在系统「文件」App 里连接服务器，再用书库的「导入书籍文件夹」加入。

### 2. App 内新建连接

NAS 页右下角 ➕：

| 字段 | 说明 |
|---|---|
| 名称 | 例如「家里的飞牛」 |
| 内网地址 | `http://192.168.1.10:5005` |
| 外网地址 | `https://nas.example.com:5006` |
| 账号 / 密码 | 飞牛用户名密码；密码只进系统钥匙串 |
| 分类目录 | 默认 漫画 / 整理 / 短剧，可改成飞牛上的实际路径 |

### 3. 内外网怎么判断

不是猜「我在哪张网」，而是探「哪条路能通」：

1. 先用内网地址发一次 `PROPFIND Depth:0`，2.5 秒超时；
2. 通了 → 显示「内网直连」，直接使用；
3. 不通 / 超时 / 返回的不是 WebDAV → 切外网地址重试，通了显示「外网连接」；
4. 结果缓存 5 分钟；切网或请求失败立刻作废，下次进入重新判断。

分类入口进去后**固定访问该分类配置的飞牛目录**，NAS 页不含小说。

### 4. 分类入口与书库长得一样

NAS 页的三个分类（漫画 / 整理 / 短剧）用的是**和书库首页同一个卡片组件**：
图标圆角底 + 标题 + 一行目录说明 + 右侧部数 + 箭头。右侧数字是进去时对三个目录
各列一层、数子文件夹得到的（并发请求，练不上的分类不显示数字）。

### 5. 修改 / 删除连接

三个入口，任选其一：

| 入口 | 操作 |
|---|---|
| 连接列表左滑 | 「编辑」/「删除」 |
| 连接列表长按 | 编辑连接 / 删除连接 |
| 进入连接后右上角 ✏️ | 编辑地址、账号、分类目录 |

编辑保存后会清掉内外网探测结果并立即重连，标题、分类路径、卡片数量都跟着新值走。
密码留空表示不改（原密码仍在钥匙串）。

### 6. NAS 上的目录规则

与书库完全一致，进去就是**书库那三层**，只是少一个小说分类：

| 层 | 整理 | 漫画 | 短剧 |
|---|---|---|---|
| ① 书名 | 每个文件夹一本书，行上显示「N 章」 | 每部漫画一个文件夹 | 每部剧一个文件夹 |
| ② 章节 | 每个子文件夹一章 | 部 → 话；有「PDF包 / 图片包」时按包分段 | 剧照包 + 每集（显示大小 · 时长） |
| ③ 阅读 | 正文 → 插图 → 章末音视频 | 满宽连排（点图看大图）/ pdf 按页 | 连排剧照 / 视频播放器 |

- 目录是**逐层读取**的（进一级列一级），不会一进去就把整棵树扫一遍。
- 图片下载到 App 缓存（Caches/RemoteImages）再显示；视频不下载，直接流式播放。
- 结构不规范（分类根下直接放文件）时，会把该目录本身当成一本书，仍按上面的方式呈现；
  想按原始目录逐层看，用右上角「原始目录」。
- NAS 上的视频与本地同一套播放器：全屏、旋转、长按倍速都可用。

**阅读操作也和书库同一套：**

| 操作 | 书库 | NAS |
|---|---|---|
| 记住读到第几段 / 第几张 | 有 | 有（同一份进度，退出重进回到原位） |
| 章节列表标出「在读」 | 有 | 有（🔖） |
| 章末「下一章 / 下一集」 | 有 | 有（页内替换，返回仍是章节列表） |
| 关掉大图滚回刚看的那张 | 有 | 有 |
| 大图关闭手势 | 下滑关闭；最后一张从右边缘继续左滑也关闭 | 同左（同一套阈值，逐项对齐） |
| 左滑删除书 / 章节、多选删除 | 有 | **无**（远端只读，删文件请用飞牛的「文件管理」） |
| 导入书籍、重新扫描 | 有 | **无**（NAS 内容由飞牛管理，App 只读不写） |

差别只有最后两行：本地书库能写盘，NAS 走 WebDAV 只做读取，避免误删服务器上的文件。

### 7. 图片缓存上限与清理

**设置 → NAS 图片缓存**：

| 项目 | 说明 |
|---|---|
| 上限 | 128 / 256 / 512 / 1024 / 2048 MB / 不限制，默认 512 MB |
| 已占用 | 显示当前占用的空间与文件数（进入设置时统计一次） |
| 清理图片缓存 | 二次确认后清空，只删本机缓存，NAS 原图不受影响 |

- 每次缓存一张图，都会在后台检查一次总量；**超出上限按「最久未修改」从旧到新删**，直到回到上限以内；
- 上限改成更小的值时**立即裁一次**，不用等下次浏览；
- 上限 = 不限制时不做自动淘汰，只在系统存储紧张时由 iOS 自行清理 Caches 目录；
- 淘汰只影响已下载的缓存图，不影响阅读进度、书签与任何 NAS 上的文件。

### 8. 预取与并发（为什么翻页不卡）

- 剧照 / 漫画滑动时，每张图出现就**预取前后各 2 张**，滑到下一张基本不用等；
- 同时最多 **4 个下载**在飞（同一张图正在下载时，后续请求直接等结果，不重复走网络）；
- 会话限 4 条连接 / 主机；**https 时由系统自动协商 HTTP/2**，一个连接跑多个请求（多路复用），
  这是内网之外最接近 SMB 单连接模型的免费升级；
- 连接页底部会显示实际协议：看到「HTTP/2（多路复用）」说明已生效，显示「HTTP/1.1」说明
  当前是 http 或服务端没开 h2（飞牛 WebDAV 走 https 时一般支持）。

## 五、阅读时自动收起底部标签栏

进入正文、漫画、剧照或视频页面，底部「书库 / NAS / 设置」自动收起，正文占满整屏；
返回列表立即恢复。iPad 上标签栏在顶部（系统规范），同样会收起。

## 六、第一次连接可能遇到的提示

- 系统会问「允许访问本地网络」——必须允许，否则连不上内网地址；
- 内网 http 已放开 ATS（只为你自己填的 NAS 地址），外网仍建议 https；
- 连不上时依次查：飞牛 WebDAV 是否开启、端口、账号密码、手机是否在同一 Wi-Fi、外网端口映射。
