# 短剧 / NAS 使用说明

## 一、底部分三页

书库 · NAS · 设置（设置固定在最右）。打开 App 默认停在书库。

> iPhone 上标签栏在底部；iPad 上按系统规范显示在顶部，顺序一致。
> 阅读器右上角的齿轮仍然可以直接弹出设置，不用退回标签页。

## 二、短剧（书库与 NAS 都有）

```
短剧/
├─ 逆光而行/              ← 剧名文件夹 = 一部
│  ├─ 剧照/               ← 剧照包：图片
│  │     001.jpg 002.jpg …
│  └─ 视频/               ← 视频包：每集一个文件
│        第01集.mp4
│        第02集.mp4
├─ 只有视频的一部/         ← 没有剧照也能识别
│  └─ 全集.mp4
└─ 散装短片.mp4            ← 短剧根下直接放视频 = 一部单片
```

进入一部剧后：

| 位置 | 表现 |
|---|---|
| 剧照 | 单独一段，点进去按**漫画方式满宽连排**，点图看大图 |
| 视频 | 单独一段，每集一行，右侧显示 **大小 · 时长**（128.4 MB · 12:36） |
| 播放 | 与「整理」里的视频完全一致：内联播放、可全屏、长按倍速 |

时长是滚动到该行才读的（本地读文件头，NAS 上带认证头读），读到就缓存，不会一进页面就发一堆请求。

## 三、NAS（飞牛）

### 1. 飞牛侧准备

1. 控制面板 → 文件共享 → **WebDAV** 开启（默认端口 5005 http / 5006 https）；
2. 给账号读写权限，记下共享路径（默认就是共享目录名）；
3. 外网访问：DDNS 或端口映射，建议外网走 https。

> **SMB 说明**：iOS 没有给 App 的 SMB 客户端接口，本项目不硬做 SMB 协议栈。
> 要用 SMB 就在系统「文件」App 里连接服务器，再用书库的「导入书籍文件夹」加入。

### 2. App 内新建连接

NAS 页右下角 ➕：

| 字段 | 说明 |
|---|---|
| 名称 | 例如「家里的飞牛」 |
| 内网地址 | `http://192.168.1.10:5005` |
| 外网地址 | `https://nas.example.com:5006` |
| 账号 / 密码 | 飞牛用户名密码；密码只进系统钥匙串 |
| 分类目录 | 默认 漫画 / 整理 / 短剧，可改成飞牛上的实际路径 |

### 3. 内外网怎么判断

不是猜「我在哪张网」，而是探「哪条路能通」：

1. 先用内网地址发一次 `PROPFIND Depth:0`，2.5 秒超时；
2. 通了 → 显示「内网直连」，直接使用；
3. 不通 / 超时 / 返回的不是 WebDAV → 切外网地址重试，通了显示「外网连接」；
4. 结果缓存 5 分钟；切网或请求失败立刻作废，下次进入重新判断。

分类入口进去后**固定访问该分类配置的飞牛目录**，NAS 页不含小说。

### 4. NAS 上的目录规则

与书库完全一致（漫画：部 → 话；短剧：剧照包 + 视频包），只是少一个小说分类。
目录是**逐层读取**的（进一级列一级），不会一进去就把整棵树扫一遍。

图片会下载到 App 缓存（Caches/RemoteImages）再显示，视频不下载、直接流式播放。

### 5. 图片缓存上限与清理

**设置 → NAS 图片缓存**：

| 项目 | 说明 |
|---|---|
| 上限 | 128 / 256 / 512 / 1024 / 2048 MB / 不限制，默认 512 MB |
| 已占用 | 显示当前占用的空间与文件数（进入设置时统计一次） |
| 清理图片缓存 | 二次确认后清空，只删本机缓存，NAS 原图不受影响 |

- 每次缓存一张图，都会在后台检查一次总量；**超出上限按「最久未修改」从旧到新删**，直到回到上限以内；
- 上限改成更小的值时**立即裁一次**，不用等下次浏览；
- 上限 = 不限制时不做自动淘汰，只在系统存储紧张时由 iOS 自行清理 Caches 目录；
- 淘汰只影响已下载的缓存图，不影响阅读进度、书签与任何 NAS 上的文件。

## 五、阅读时自动收起底部标签栏

进入正文、漫画、剧照或视频页面，底部「书库 / NAS / 设置」自动收起，正文占满整屏；
返回列表立即恢复。iPad 上标签栏在顶部（系统规范），同样会收起。

## 六、第一次连接可能遇到的提示

- 系统会问「允许访问本地网络」——必须允许，否则连不上内网地址；
- 内网 http 已放开 ATS（只为你自己填的 NAS 地址），外网仍建议 https；
- 连不上时依次查：飞牛 WebDAV 是否开启、端口、账号密码、手机是否在同一 Wi-Fi、外网端口映射。
