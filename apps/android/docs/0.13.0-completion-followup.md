# Android 0.13 功能清单后续补齐

日期：2026-10-23。对照 [双端功能完成与补齐清单](../../../docs/product/plans/0.13.0-client-completion-review.md)、[版本计划](../../../docs/product/plans/0.13.0.md)、[Android 客户端说明](../../../docs/product/clients/android.md) 和 [能力矩阵](../../../docs/product/matrix/capability-matrix.md)。本轮只修改 `apps/android`，保留之前的未提交修改。

## 功能结论与本轮修改

Android 已承诺的导入、阅读、密码、搜索、复制、书签和同步主要入口已有实现。本轮完成 A04 的端内重试，并补齐已有打开及搜索流程的边界；A02/A03 的真机与真实出版物验收不因新增自动化而标记完成。

| 清单项 | 本轮结果 |
|---|---|
| A01 大文档搜索 | 新增按最近使用淘汰的会话内文字缓存，按 UTF-16 大小和每条开销权重限制为 8 MiB，超大单页不缓存。更换关键词复用原文，续查复用来源和末页坐标。关闭和内存紧张时清理，不写磁盘索引或解密副本。页内提取及命中定位检查取消，旧任务不能返回已取消的命中。首次全书解析仍慢，性能验收保持待完成 |
| A02 代表性设备 | 本轮重新执行 API 35 专用模拟器的原生流程；没有连接 Android 物理设备，不将模拟器结果写为真机通过 |
| A03 兼容与资源 | 新增 RC4 40/128 位及 AES 128/256 位自建密码样本，验证允许/禁止提取两类权限及缓存回收后行为；仍需复杂真实 PDF/EPUB、低配置设备和长期使用记录 |
| A04 端内重试 | PDF/EPUB 解析、已保存位置校验及首屏渲染失败提供“重试打开 / 返回书架”。重试释放旧页面/文档资源、重新校验原文件和位置、保留正式时间和书签；密码 PDF 重新输入密码。连续失败后恢复原文件，可在同一 Activity 继续打开 |
| 打开阶段隔离 | 首屏渲染确认之前屏蔽翻页、搜索、书签、目录/排版和正文位置提交，避免操作使初始化回调失效、跳过同步准备或生成阅读时间 |

2026-10-23 本轮没有增加 Android PDF 裁边、OCR、批注或 DRM。2026-10-24 按用户新增授权补齐 Android PDF 显示裁边，见 [裁边实现与验证记录](0.13.0-pdf-crop.md)。现有 TXT 手势、进度条、选文及同步规则作为回归基线。

## 测试

- **217 项 Android 单元测试通过，0 失败、0 跳过；lint 通过**。新增覆盖页内提取取消、命中定位时取消、取消后重搜、会话缓存及内存回收、RC4/AES 和提取权限、连续失败恢复、重试后密码重新输入、首屏打开期间动作隔离。
- **6 项原生流程通过**：EPUB 离线资源/排版/书签/复制/重开，EPUB 主题及常亮，PDF 密码错误重试/翻页/重开，PDF 长按持续拖动复制，PDF 搜索停止及书首重启，以及 PDF/EPUB 原路径文件损坏后的连续重试/恢复。后一项分别执行两种格式，断言原位置、时间与书签保留。
- 密码兼容样本为自建文件，四种算法分别测试允许/禁止提取共八种组合；这是 Robolectric/PDFBox 引擎验证，不代替真实出版物和物理设备验收。
- 新增取消回调最初触发 API 24 接口的 lint 错误，已改为项目内接口，保留 min SDK 23；没有通过压低 lint 等级或提高 min SDK 绕过。
- 构建：**Android 0.12.0 build 90**，使用根 `make build-android-debug`；版本名保持不变。开发中的 build 87–89 已由后续构建替代。
- 按本次只处理 Android 的要求执行 Android 单元、lint、构建和模拟器测试；没有运行会构建并递增其他客户端版本的全仓 `make check`，也没有执行 Alpha/发布流程。

## 千页 PDF 测量

使用同一 `pdf-large.pdf`（1,000 页、440,028 B），同一专用 `xlib013-validation` 模拟器（API 35、arm64、2 GiB、软件图形），旧 build 86 与新 build 90 各三轮。计时过程不并行编译、不清 OS 缓存，不作为物理设备性能承诺。首次全书无命中沿用脚本原顺序，在首批及第二批搜索后执行，不能称为完全无缓存冷启动。

测量结果见本机 `artifacts/android-013-completion/search-measurements.json` 与下方最终汇总。正式位置、阅读时间、关闭恢复、每批 200 条和全书无命中均有断言。取消测量会先清理会话文字缓存，并确认千页扫描在请求取消时仍未结束；缓存查询早已完成的旧测量保留为无效取消样本，不用于取消速度结论。

| 指标 | build 86 三轮中位数 | build 90 三轮中位数 |
|---|---:|---:|
| 首批 / 第二批搜索 | 278.7 / 146.7 ms | 294.9 / 156.7 ms |
| 本会话首次全书无命中 | 7101.2 ms | 6922.8 ms |
| 缓存建立后更换关键词，全书无命中 | 原测试未单独采集 | 11.4 ms |
| 取消请求至任务退出 | 4.6 ms | 0.23 ms（每轮均断言仍在执行） |
| 应用 PSS 三轮采样峰值的最大值 | 133.6 MiB | 141.0 MiB |

首次扫描的变化较小，首批/第二批也有波动，不能据此声称首次全书解析热点已解决。缓存主要改善同一会话内更换关键词及重复扫描；超出缓存预算的书籍会发生淘汰，不承诺所有文档后续搜索都只需十几毫秒。PSS 是应用进程采样，不包含独立 WebView/GPU 进程的完整口径。

开发中的 build 89 曾在逐字形调用取消回调时测到首次扫描中位 7839.2 ms；随后改为每 64 个字形检查，并在提取开始/结束及命中定位前后继续检查。该阶段的日志保存在 `pdf-final-per-glyph-cancellation.log`，不混入 build 90 最终统计；页内取消、取消后重搜和密文缓存边界重新通过测试。

## 剩余验收

首次全书扫描的热点优化、代表性物理设备及较低配置设备、复杂真实文件和长期内存测试仍待完成。现有模拟测量不能替代这些验收，也不能据此批准统一性能预算或升级为 0.13.0。本轮未创建分支、commit、push 或部署，所有修改保持未提交。

本机证据位于忽略目录 `artifacts/android-013-completion/`：`unit-lint.log`、`native-reader-final.log`、`pdf-baseline.log`、`pdf-final.log`、`search-measurements.json`、`build-final.log`；探索阶段失败与取消测量修正记录另行保留。最终包为 `artifacts/android/0.12.0/xlib-debug-90.apk`。
