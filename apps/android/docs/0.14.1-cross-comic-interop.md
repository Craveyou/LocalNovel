## 固定协议

共同测试必须在**同一个**临时 HTTPS/PostgreSQL 服务、同一个 run 下按下列顺序运行，不能为每阶段重新启动服务：

1. Android `seed`：实际导入、校验并解码四份公共原包；使用 comic-order-v1 生成 page10、y=0.234567；正式 SQLite 持久化、DocumentSyncSession 上传。记录原始阅读时间。
2. iOS `accept-android`：真实 iOS 阅读器接收 Android 的原位置/原时间，实际移动到 page11、y=0 并上传。
3. Android `accept-ios`：检查远端 platform=ios、page11、y=0；正式 DocumentSyncSession 提示并接受，SQLite 恢复其原时间，接受操作本身 POST 数为 0；实际解码长图，正式移回 page10、y=0.500001，单调更新阅读时间并上传。对较早和较晚时间的异 manifest 均检查 422 且 iOS 原记录不变。
4. iOS `accept-android-delete`：真实接收 Android 较前页但更新的时间，删除四本云端进度；同会话继续移动和比较后仍为空。
5. Android `verify-deleted`：**只读**四本云端为空，检查本地位置、原始字节和书签保留、v1 无漫画记录；不启动会补上传的全新正式阅读会话。Android 自己删除后的暂停另有 ComicInteropDeviceTest 覆盖。

账号固定为 `${run}-cross-comic@example.com`；Android 设备 UUID 为 `01410000-0000-4000-8000-000000000001`，名称 `Android cross comic`，平台由真实 SyncApiClient 注册为 android。iOS 必须使用不同 UUID 和真实 ios 平台。四份原包依次为 comic-basic.cbz、comic-basic-rar4.cbr、comic-basic-rar5.cbr、comic-basic-rar4-solid.cbr。原始 SHA-256 / 大小和实际解析 manifest 与公共 fixture JSON 逐一比对。

## 运行方式

应用已安装于 `emulator-5554`（本任务专用 API35 / arm64 / 4 KiB 模拟器）；构建产物：

- 应用：`artifacts/android/0.13.1/xlib-debug-108.apk`
- 测试 APK：`apps/android/app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk`
- 测试类：`com.xlib.txtreader.CrossComicInteropDeviceTest`，单个测试 `stagedAndroidIOSComicContinuation`。

公共编排脚本传入已有临时服务环境变量，仓库根执行：

```sh
ANDROID_SERIAL=emulator-5554 \
XLIB_COMIC_INTEROP_STAGE=seed \
sh apps/android/scripts/test-cross-comic-stage.sh
```

必要环境为 `TEST_RUNNER_XLIB_DOC_INTEROP_URL`、`TEST_RUNNER_XLIB_DOC_INTEROP_RUN`、`TEST_RUNNER_XLIB_DOC_INTEROP_CERT`。URL 仅允许 `https://localhost:<port>`，证书信任只在 instrumentation 进程生效；脚本建立并清理本阶段 adb reverse，不输出 token。阶段也可作为位置参数传入。iOS 运行期间 Android 无 instrumentation 在途，防止同一模拟器测试互相中断。

脚本映射为 `-e interopStage seed|accept-ios|verify-deleted`，以及 `interopUrl`、`interopRun`、`interopCertificate`。仅允许一次性 Android 模拟器；从 instrumentation 的 `OK (1 test)` 判断成功，不能只看 adb 退出码。

跨进程状态在应用私有 `files/cross-comic-${run}.json`，只含本地书籍 ID 与 seed 时间，不保存 token。每阶段证据在 `/sdcard/Android/data/com.xlib.txtreader/files/cross-comic-${run}-${stage}.json`，可用 adb pull 归档，包含实际客户端平台、位置、时间、设备和服务版本。`verify-deleted` 完成后保留本地原书和书签用于核验，不自动清空应用。

## 验收边界

seed 自检只能证明 Android 上传，不代表 Android↔iOS 完成。五阶段实际通过后才记录跨端模拟器证据；物理设备峰值性能、完整语料和 G1/G3 的其他出口仍需分别验收，不能据此开始未冻结的 Kindle 实现。
