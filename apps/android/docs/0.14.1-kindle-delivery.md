# Android 0.14.1 Kindle 接入

2026-10-25。本任务仅修改 `apps/android`，消费公共 owner 已交付的 `packages/kindle-core`、`kindle-text-v1`、六个原包/JSON、locator 向量及 Backend PG005；不改共享规范、iOS 或服务实现。此记录替代早期接入准备文档中“公共依赖尚未交付”的当前结论。

## 实现

- Gradle 从同源 entities/decoder/core 三文件生成应用资源，随包包含固定 MIT 许可；不复制另一套规范正文算法。
- 每次解析使用独立、不可见的 WebView JavaScript 宿主，只有可信公共核心能执行。宿主精确读取原文件范围、支持协作取消，禁用文件/content/网络/持久存储，不将作者 HTML 作为脚本执行。解析在后台调用，所有 WebView 生命周期由主线程调度；退出、取消和超时销毁宿主。
- 原包保留字节身份；MOBI6、PalmDOC、HUFF/CDIC、KF8 和混合（固定选择 KF8）由共享核心输出正文、图片、有效目录、内部导航、源跨度及封面。DRM/固定版式/损坏及资源限额沿用公共拒绝边界。
- `ReflowDocument` 仅抽出 EPUB/Kindle 共用显示模型，Kindle 保留自己的 `format/profile/textHash/全书 UTF-16` 定位；复用现有 TXT 风格的阅读底板、主题、字体、字号、行距、菜单、进度条、目录、搜索、复制和书签交互，不转换 EPUB、不使用屏幕页码定位。
- 加载后校验 DOM 文本逐字等于公共章节正文；失败不保存目标位置。选区从 DOM 端点映射回规范正文，复制去除图片占位，搜索用等长空格代替图片占位；沿用 2–32 字符、大小写不敏感、不重叠、200 条分批和主动回绕。无可搜索文字时入口禁用。
- 书签添加/去重/单删、临时预览返回和重开恢复沿用文档会话；重排、选择、恢复及接受云端不制造新阅读时间。同步先核对原文件、正文哈希/长度/字素边界，接受远端保留原时间；只上传位置与正式阅读时间。
- SQLite v5 typed `text_hash/profile/text_offset/text_length`；事务内逐列双向 EXCEPT 校验 v4→v5 复制，外键复验，已有 TXT/PDF/EPUB/漫画位置及书签键保持，未知 profile/缺失原文件保留。迁移前关闭外键、迁移后恢复，失败回滚。
- 内置封面使用可重建 256px 缩略缓存，最多 64 项/8 MiB；不改原文件、书签或位置。许可证入口在阅读排版设置内。
- 修复同步在途时丢弃刷新请求的问题：合并为当前请求结束后的再比较，覆盖临时浏览返回和阅读事件，不等待下一次周期触发。

WebView 宿主线程语义依据 [Android WebView API](https://developer.android.com/reference/android/webkit/WebView#addJavascriptInterface(java.lang.Object,%20java.lang.String))；此接口仅暴露给随包可信核心。没有引入新的 native JS 库或提高最低 Android API。

## Android↔iOS 五阶段入口

`sh apps/android/scripts/test-cross-kindle-stage.sh seed|accept-ios|verify-deleted`，也可传 `XLIB_KINDLE_INTEROP_STAGE`。消费现有一次性 HTTPS 服务的 `TEST_RUNNER_XLIB_DOC_INTEROP_URL/RUN/CERT`，不自己为每阶段启动数据库，不输出 token，仅允许模拟器和 localhost。

六个原包，账号 `run + '-cross-kindle@example.com'`，设备 ID `01410000-0000-4000-8000-000000000101`。seed 为最后章节 offset3；iOS 接受后到 offset10；Android 接受保持原时间、POST=0，再以更新实际时间回到 offset1；iOS 接受后删除并验证会话暂停；Android 末阶段只读验证为空、本地原包/书签/位置保留、v1 隔离。所有偏移先经公共正文的字素边界规范化。accept-ios 还检查异 textHash/length 在较早/较晚时间都被 422 拒绝且旧行保留。
