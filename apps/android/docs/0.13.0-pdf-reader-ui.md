# PDF 阅读界面与裁边交互修正

日期：2026-10-24。只修改 Android；保留现有未提交修改，沿用工作区当前 0.13.0 版本名。

## 用户反馈与原因

- PDF 使用独立的常驻文字按钮界面，与当前 TXT 阅读器的浮层菜单不同。
- 裁边默认关闭时同时禁用了两个滑块；直接拖动不会启用，点击完成仍保持关闭。旧原生测试先点击开关、再通过无障碍 SET_PROGRESS 设置值，未覆盖用户直接用手指拖动的路径。
- 每次 PDF 导航重新执行 Java 位图渲染和文字提取，包括回到已看页面；过期导航也会先渲染再丢弃。选择栏出现时改变正文布局，增加视觉跳动。

## 当前行为

- TXT 与 PDF 共用 `ReaderChrome` 阅读底板和菜单容器，复用当前 `UiKit` 的圆角、阴影、浅深色配色、图标背景及进度条。TXT 保持现有布局和行为；PDF 正文替换内容渲染器，使用同一浮层结构。
- PDF 正文中间 30%–60% 区域点按展开菜单；菜单打开时点正文收起，不翻页。左右区域点按及基础倍率横滑翻页；缩放后平移。顶部为缩放、搜索、主题、常亮、裁边，底部为跳页、书签、前后页、进度和更多操作；同步在更多操作中。
- 菜单及复制栏覆盖在正文上，不挤压正文或改变页面坐标。系统返回先关闭选文/菜单，再按原有临时阅读返回规则处理。
- 裁边面板靠底部显示，上方页面实时预览。两个滑块保持可用，实际手指拖动自动启用；独立 0–30%、默认 10%/10%、恢复原页和进程内跨 PDF 共用规则保持。
- 浅色/深色面板与当前阅读主题一致。裁边、切换主题及打开菜单均不生成阅读进度事件，不改变源文件、书签和正式阅读时间。

## 性能与资源

- 未加密 PDF 优先用 Android `PdfRenderer` 原生渲染；PDFBox 继续提供原始文本、权限及坐标。密码文件和原生不支持的情况回退已有 PDFBox 渲染。
- 主线程只操作既有页面/变换；渲染仍在单一工作线程。开始渲染前检查任务代次，过期排队任务跳过；当前页内定位复用位图。
- 最多缓存三张已看页面，按 LRU 在 12 MiB 总位图预算内淘汰离屏页；当前页可以单独超过预算。往返已缓存页面立即复用，不等待工作线程。内存紧张回收离屏页，重试/退出释放全部；不增加磁盘页缓存或解密副本。
- 字符命中检查直接换算矩形坐标，不再为每个字符/每次拖动创建屏幕 RectF；正常页面绘制复用边界矩形。

## 验证与证据

- **225 项 Android 单元测试通过，0 失败/跳过；lint 无错误。** 新增当前阅读底板、菜单默认隐藏/点按展开/返回收起、菜单不改变正文尺寸；阻塞渲染线程时仍能立即返回缓存页、内存紧张保留当前页等断言。
- Robolectric API 35 的 ParcelFileDescriptor 原生桥缺少宿主 JDK 方法，使用兼容回退；真实 Android API 35 原生测试另行断言原生渲染器始终启用，不能将宿主回退的单测称为原生引擎验证。
- 原生裁边测试用真实 DOWN/MOVE/UP 连续事件拖动左右滑块，断言默认关闭时可直接启用、百分比改变、页面红色边缘实际消失、关闭面板后仍保留；页面位图、视口尺寸、原字节/哈希、正式位置/时间和书签保持。继续覆盖缩放后长按拖动复制、重开、跨书、恢复及浅深色界面。
- 原生渲染验证使用带非零原始 CropBox 的 0/90/180/270 度页面，逐一检查字形与文字坐标重合；同一加载文档、1080px 输出、1,800 个矢量矩形样本，分别对原生与 PDFBox 路径测量三轮。只代表该模拟器/样本，不外推到所有文件或物理设备。
- 专用 API 35 arm64 模拟器 **8 项原生流程全部通过**：原有 6 项阅读回归及原生渲染/裁边两项流程；测试明确等待新窗口完成切换，并隔离每项基线的会话裁边设置。浅色菜单、裁边实时预览、关闭后显示及深色面板截图已人工检查。
- 最终矢量样本三轮中位数：原生渲染 **30.2 ms**，PDFBox **70.5 ms**，均含相同的文字几何提取；这是同一已加载测试文档的页渲染测量，不是整本打开/搜索或真机性能结果。
- 构建使用根 `make build-android-debug`，最终 **0.13.0 build 94**，包为 `artifacts/android/0.13.0/xlib-debug-94.apk`。仅运行 Android 检查，没有运行会构建其他客户端的全仓 `make check`。未创建分支、commit、push 或发布。

本机日志、测量和截图保存在忽略目录 `artifacts/android-pdf-reader-ui/`：`unit-lint-final.log`、`native-reader-final.log`、`pdf-rendering-measurements.json`、`pdf-reader-menu.png`、`pdf-crop-preview.png`、`pdf-reader-cropped.png` 及深色截图。开发阶段失败另行保留，不计入最终通过结果。代表性真机、复杂真实出版物及长期内存测试仍需后续验收。
