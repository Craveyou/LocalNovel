# Android 0.14.1 全流程与已部署 Backend 测试

日期：2026-10-25。按用户要求，服务交互直接访问 Android 当前默认服务器 `https://xunit.cc/xlib/backend`，不以本地临时服务代替。本轮只修改 Android 测试/说明与标准构建号；不修改 iOS、Backend、部署配置或签名材料，不创建分支、commit 或 push。

## 环境和执行方式

- Android API35 / arm64 / 4 KiB 隔离模拟器，当前 0.14.1 共用应用源码的 Debug build117；既有 release116 不被替换为新的正式发布。
- `SyncApiClient` 使用系统正常 TLS 信任与主机名验证，无 localhost 转发、测试证书或 SSL 绕过。`GET /health` 实际返回 `{"status":"ok"}`；该接口不返回服务器 build，不能据此宣称部署的具体 Git revision。
- 每轮生成独立 `android-e2e-<时间>-<随机值>@example.com` 账号及独立设备；仅对本轮账号/样本执行写入和删除。账号邮箱和 token 不进入测试报告；令牌由真实同步设置使用 Android Keystore 保存。
- 第二设备使用真实 Android `SyncApiClient` 注册和访问同一服务器，用于验证账号隔离后的同账号接续；不冒充 iOS 双端测试。

```sh
# 先安装 Debug APK 和最新 androidTest APK；仅用于隔离模拟器。
XLIB_TEST_SERVER_URL=https://xunit.cc/xlib/backend \
XLIB_TEST_SERVER_WRITES=isolated-test-data \
sh apps/android/scripts/test-server-flow.sh
```

普通测试不会默认触发服务器写入。上述入口显式启用 `ServerBackendFlowDeviceTest`，要求服务器地址与客户端默认配置一致。`XLIB_TEST_PREVIOUS_RUN` 可指定本任务已创建的一轮账号，复核/清理其残留进度及设备，不能指定普通用户账号。

## 功能覆盖

| 范围 | 实际检查 |
|---|---|
| 书架 | 应用 URI 导入链路、原文件字节、重复导入去重、真实左滑后保持菜单、修改书名/作者、长按显示删除、取消/确认、本地文件及书签清理 |
| 阅读 | TXT、PDF、EPUB、CBZ、RAR4/RAR5/固实 CBR、MOBI6/PalmDOC/HUFF/KF8/混合/长正文 Kindle；翻页/跳转、图片、主题/排版、旋转、重开恢复 |
| 搜索和复制 | PDF/EPUB/Kindle 搜索停止/重启和临时预览返回、原生长按及复制浮层、emoji、选文不改正式阅读时间；无文字漫画入口禁用 |
| PDF | 密码重试、坏文件原地重试、裁边拖动/复制参数/恢复、文字几何和渲染 |
| 服务器注册 | 实际同步设置输入邮箱/设备名并点击“同步刷新”、加密凭据、第二设备注册、设备列表 |
| 上传与接续 | 13 本独立书逐本由实际 Reader Activity 提交位置；从服务器核对 hash/size/locator/时间/设备；第二设备新位置经真实提示按钮接受，保留远端原时间且不反向覆盖 |
| 时间与正文身份 | 阅读前比较不制造事件、返回较前内容但较新时间仍可上传；漫画 manifestHash / Kindle textHash 不一致时 422 拒绝，旧云端版本保持 |
| 云端删除 | 经实际确认按钮删除；同一阅读会话继续移动和刷新仍暂停上传，本地书/书签/位置保留；关闭重开恢复上传且不刷新既有阅读时间 |
| 清理与撤销 | 先查询剩余进度，仅删除仍存在的本轮数据，避免重复 DELETE；撤销第二设备并验证其请求 401/403，再撤销本机令牌；本地凭据清除 |

普通 UI 回归不携带服务器凭据；服务器测试独立运行，实际使用启用同步的应用会话。书架 URI 导入测试不等同于真实第三方文件提供商的系统选文件验收。
