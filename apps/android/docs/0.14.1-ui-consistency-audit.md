# Android 界面规范统一检查

日期：2026-10-24。范围为 Android 现有界面；继续采用当前 TXT 阅读器的中性绿配色和浮层结构。本次没有迁移 UI 框架或增加 Material 依赖，也不代表 0.14.1 的格式功能全部完成。

## 统一规则

- 普通弹窗使用 28dp 圆角；按钮/输入控件采用至少 16dp 圆角。阅读浮层保留当前顶卡 22dp、底卡 24dp 的视觉规范。
- 图标可点击区域至少 48×48dp，图形居中并保留内边距；按钮、选择项提供圆角按压反馈。不可用功能保持禁用及低透明度，不插入阅读提示。
- 编辑书籍、同步配置与阅读弹窗的输入框采用 56dp 最小高度、16sp 字号和主题化焦点边框。
- 浅深主题共用 UiKit 色值，明确区分背景、表面、次级表面、正文和操作色。删除按钮保留红色危险操作色。
- 原生弹窗的自定义内容统一保留 24dp 水平内边距。弹窗最大宽度 560dp，两侧至少预留 24dp；自定义长面板可以滚动，高度受可用窗口和屏幕 80% 限制，键盘出现时调整。
- 短确认操作靠末端排列；空间不足时换行。原生三操作弹窗垂直排列，避免长按钮相互挤压。
- 顶部阅读工具栏及设置选择行在窄屏按需换行，保留触控尺寸。图标提供中文无障碍描述。

参考：[Android Views 无障碍触控目标](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views)、[Material Android Dialog 文档](https://github.com/material-components/material-components-android/blob/master/docs/components/Dialog.md)、[Android 自适应图标](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)。本实现采用这些原则与项目现有设计规范，不声明已完整迁移到 Material 3 组件库。

## 检查范围与实现

| 区域 | 处理 |
|---|---|
| 书架 | 检查添加、管理、卡片更多/删除、左滑与长按删除入口；统一按钮触控区域和按压反馈 |
| 书籍编辑/确认 | 编辑、删除、云端进度删除、远程进度跳转、书签删除、关闭同步和设备删除复用圆角确认卡片；操作末端对齐，内容可滚动 |
| 设置 | 常规/阅读/同步标签、概要卡片、选择项、步进按钮及下拉菜单；提升小字号，修正过窄下拉窗口，输入框使用共享样式 |
| 设备管理 | 加载/失败/设备列表共用有界滚动面板，异步替换内容后继续保持窗口尺寸 |
| TXT | 现有阅读浮层、复制菜单、搜索、目录/书签与阅读设置保留；扩大图标触控区域并适配窄屏 |
| PDF | 密码、重试、目录/跳页、搜索/结果、书签、字体与同步提示等原生弹窗全部改走 AppDialogs；裁边保留底部实时预览且不遮暗预览 |
| EPUB | 采用 TXT/PDF 共用 ReaderChrome 浮层；字号、主题、常亮、目录、搜索、书签及排版入口统一。点按正文显示/收起菜单，保留 WebView 原生选文 |
| 漫画预览 | 共用阅读浮层，跳页/阅读方向/错误消息使用 ReaderDialogs；纯图片搜索和书签保持禁用，无能力说明遮挡正文 |
| 启动图标 | 保留现有六瓣造型，补充主题单色层，支持 Android 13 起的主题图标 |
| 系统窗口 | 文件选择器、键盘、权限及系统剪贴板提示继续由 Android 管理 |

核心文件为 `UiKit`、`AppDialogs`、`AdaptiveRow`、`ReaderChrome`、`ReaderDialogs`。样式调整保留现有按钮回调、输入校验、取消行为和阅读状态；没有修改书籍格式/同步契约。

本轮未运行包含 iOS 构建的根 `make check`，使用其 Android 单测/lint 阶段及标准 `make build-android-debug`。物理设备、TalkBack 实际朗读及所有厂商系统/字体缩放组合未实测；横屏与窄屏布局已有自动测试覆盖。所有修改保留未提交，不创建分支、不 commit、不 push。
