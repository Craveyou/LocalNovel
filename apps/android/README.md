## 书架操作

- 右上角“添加书籍”直接打开系统选择器，支持 TXT / PDF / EPUB / CBZ / CBR；完整验证原包后加入书架。漫画提供页面/长图阅读、本地书签、重开恢复和可选进度同步。
- 左滑书籍卡片显示编辑和删除菜单，滑过菜单宽度的一半后松手保持展开；横向滑动中的少量上下偏移不触发书架滚动。右滑或点击展开的卡片收起菜单。
- 上下滑动继续滚动书架，不打开书籍或触发长按。
- 长按书籍时在卡片右侧显示删除按钮，松手不打开书籍。点击删除按钮进入删除确认，确认后删除该书及本地 TXT；取消保留书籍。点击卡片正文隐藏长按删除按钮。
- 导入中的占位卡片不提供左滑或长按删除；管理模式继续使用原有勾选和批量删除。

## 批量新增书籍

- 系统文件选择器允许多选 TXT，单次最多 20 本，单本导入仍可使用。
- 系统文件选择器没有统一的最大多选数参数；应用在接收结果时校验，超过 20 项整批拒绝，不偷偷截取前 20 本。
- 取消选择不导入；兼容单 URI 和多项 ClipData，同一批次重复 URI 只导入一次。
- 导入发布前按文件大小及完整字节内容判重，覆盖已有书架、本批次及排队批次中已准备成功但尚未显示的文件。分块读取，不把整本书装入内存，不只比较名称或文件开头。
- 同内容不同名称跳过；同名不同内容允许新增。不同编码、BOM 或换行导致字节不同的文件不视为重复，不做有损正文归一化。
- 重复项显示“书籍已存在，已跳过”，不启用占位卡片，不覆盖已有书籍、进度、书签或目录；仅清理本次导入的临时副本。结果分别统计新增、重复、失败。删除已有书籍后允许重新导入。
- 选择结束后立即在书架显示本批占位卡片，名称在后台读取；“等待导入”和“正在导入”状态均置灰、禁用，不提供打开、编辑、删除或管理勾选入口。
- 文件复制与编码检测在后台串行执行，一本失败不阻止后续文件；每本成功后立即保存并替换为可阅读卡片，不等待整批完成。失败卡片不启用，批次结束后移除并在结果中提示。
- 批次结束后移除临时占位卡片，并显示新增、重复与失败数量；不打断正在阅读的书籍。
- 每本书使用独立 ID 和临时文件，防止短时间批量导入造成 ID 冲突；失败时清理本次临时副本，不修改或删除源文件。
- 不上传书籍，不增加存储权限。Activity 销毁时停止后续导入；已经成功发布的书籍保留，等待/导入中占位状态不持久化为正式书籍。
- 验收覆盖单本、20 本、超限、取消、重复 URI、同名书籍和部分文件不可读取。

## 搜索范围

- 搜索页不显示“书内搜索”标题和书名，顶部直接显示返回、搜索输入框和搜索按钮。
- 输入框下方提供“从当前页面往后 / 从头开始”两个互斥选项。每次从正式阅读页进入时默认前者；从结果临时阅读返回时保留选择。
- “从当前页面往后”从当前阅读页起始字节 offset 搜到文件末尾；“从头开始”从 offset 0 搜索整本书。
- 切换范围清空旧结果并使旧异步回调失效，保留输入关键词，点击搜索或键盘搜索键后重新执行。
- 原有分批加载和手工“从开头继续搜索”规则保持不变；整本搜索完成后不再提示从开头继续。
- 搜索起点与正式阅读返回位置独立；从头搜索、查看结果都不得把原阅读进度重置到书首。
- 本节为 Android 新增交互要求，替代旧规范中固定只能从当前阅读位置开始搜索的描述；不改变其他客户端。

PDF/EPUB 的“搜索文档”提供“从书首搜索”选项，默认仍从当前正文位置开始；结果保留原有分批与手动回绕。搜索执行中可点击“停止搜索”或返回继续阅读；进入后台、退出阅读会取消任务，旧结果和取消异常不再弹出。重新搜索保留输入文字并建立新的搜索范围。搜索预览与返回不改正式位置和阅读时间。

PDF 在当前文档会话内复用已经提取的正文，文字缓存按 UTF-16 大小及条目权重限制为 8 MiB，并按最近使用淘汰；超大单页不放入缓存。关闭文档时清理，内存紧张时在工作线程清理。不保存磁盘文本索引或解密副本；首次未缓存页面仍须解析，不能把更换关键词后的耗时当作首次全书扫描耗时。搜索取消会检查到页内文字提取和命中定位阶段；继续加载复用当前搜索来源及末页定位数据。

## PDF/EPUB 打开失败恢复

- 文档解析、位置校验或首屏渲染失败时提供“重试打开”和“返回书架”；重试失败可以继续重试，也可以返回。
- 重试释放上一轮文档和页面资源，重新校验原文件及保存位置；原文件改变或位置不兼容时保留数据，不把旧进度套到新正文上。
- 原文件恢复后可在当前阅读器中重新打开，保留正式位置、阅读时间和本地书签；重试本身不生成阅读事件。
- 密码 PDF 的新尝试重新要求输入密码，不保存密码，不因重试绕过解锁或同步准备。
- 首屏打开完成前不接受翻页、搜索、书签和排版操作，防止中断初始化后无法建立正式阅读会话。
- 本轮实现、测试与剩余设备验收见 [Android 功能补齐记录](docs/0.13.0-completion-followup.md)。

## PDF/EPUB 阅读偏好与后台

- 两种格式沿用设置中的“保持屏幕常亮”，仅在阅读 Activity 前台生效，后台和退出时清除。
- EPUB 字体、字号、行距和明暗主题均保存到现有阅读偏好，重开恢复；排版变化不生成正式阅读事件。PDF 保持原版面。
- EPUB 手指拖动结束时立即采集正文位置，减速/后续滚动继续合并保存；后台迟到的滚动回调不提交阅读时间，选文仍不作为滚动事件。
- 本轮补齐和验证见 [Android 后续完成记录](../../docs/product/plans/0.13.0-android-followup.md)，版本名继续保持 0.12.0。

## PDF 显示裁边

- PDF 使用当前 TXT 阅读器共用的阅读底板和圆角浮层菜单。正文中间区域点按打开菜单，再点顶部设置图标“PDF 裁边”（或底部“阅读设置”）；左右点按及基础倍率横滑翻页，菜单打开后点正文收起。菜单和复制栏不挤压正文。
- 裁边默认关闭，左右默认各 10%。两个滑块始终可用，手指拖动即启用，按 1% 独立调整至 0–30%；底部面板上方实时预览，点击“完成”保留显示效果，按裁后宽度适配屏幕，继续支持缩放、平移和长按拖动复制。
- “恢复原页”立即关闭裁边并恢复左右各 10% 的默认值；仅裁剪显示后的左右边缘，旋转页面也按当前可见方向裁剪。
- 本次应用进程内所有 PDF 共用设置，退出一本书后重开、切换 PDF 仍沿用；应用进程重启后关闭并恢复默认。设置不写入偏好、书籍、同步数据或文件。
- 调整裁边不修改原 PDF、文件哈希、书签、正式进度或阅读时间。文字几何、搜索和同步继续使用原页坐标；手动裁掉正文时可减小比例或恢复原页。无 OCR 或自动检测。
- 裁边复用当前页位图，不预处理整本书、不生成裁后或解密副本。验证记录见 [PDF 裁边记录](docs/0.13.0-pdf-crop.md)。
- 普通 PDF 优先使用 Android 原生渲染，密码或平台不支持的文件保留 PDFBox 兼容路径。内存中保留最多三张已看页面，离屏页按 12 MiB 总预算淘汰（当前页可单独超过预算）；往返已缓存页和当前页内定位不重复解析。退出/重试释放，内存紧张时只保留当前页，不写磁盘页缓存。

## 阅读进度条

- 进度条左侧显示当前滑块位置的百分比，保留一位小数；拖动时立即更新，翻页及程序跳转后与滑块同步。
- 浅色和深色主题均使用 6dp 高的完整轨道与 20dp 滑块，轨道与菜单背景、已读部分与未读轨道均保持明显反差。

## 文字选择与复制

- 阅读正文长按选中词语，显示选区高亮、前后两个拖动锚点及应用内“复制 / 取消”浮层，不启动系统 ActionMode/context 菜单。正文关闭原生文本选择和智能分类；邮箱等输入框保持系统编辑行为。
- 长按选中后，手指保持按下并移动即可向前或向后扩展当前页选区；移回原词时恢复初始选区，松手后显示“复制 / 取消”浮层。松手后仍可拖动前后锚点微调。
- 拖动任一锚点调整当前页内的范围，支持跨行；不自动翻页或跨页选择。两个端点不能交叉或形成空选区。
- 只有点击“复制”才将原始选中文本写入系统剪贴板；保留换行，不包含书名、页码或阅读 offset。不上传内容，不依赖后端。
- 选择操作复用分页 StaticLayout 坐标，不重新排版，不改变阅读进度。字符选择索引与持久化字节 offset 分离。
- 进入选择时关闭自动翻页；复制或取消后由用户重新开启。拖动锚点不触发翻页、菜单开关或边缘返回。
- 点击正文其他位置只取消选择，不同时翻页；返回键先取消选区，不退出阅读。拖动锚点时隐藏操作浮层，松手后重新定位；页面重新绑定、窗口失焦或离开阅读界面时清除选区。
- 高亮和锚点随正文颜色适配阅读主题；空页面不能选词。

本功能属于 Android 客户端阅读交互，不自动改变其他客户端或同步契约。

### 验证

在 `apps/android` 运行 `./gradlew testDebugUnitTest lintDebug assembleDebug`。

真机验收：长按中文/英文 → 分别拖动两个锚点跨行 → 点击复制 → 粘贴核对原文；
覆盖首尾行、标点、emoji、浅色/深色、自定义字体及行距、自动翻页开启、搜索高亮；
确认取消选区后正常翻页，阅读进度不因选择发生改变；长按前后均不得出现系统文本操作菜单。复制成功后的系统剪贴板通知不属于选择菜单，不屏蔽。厂商独立识屏/辅助服务可能在应用之外拦截手势，须在目标手机单独确认，不能承诺应用能禁用全部系统级识屏。

漫画原生构建另需 Android NDK 27.2.12479018 和 CMake 3.22.1；固定源码由 packages/native-archive 提供。ABI、API23 和 16KiB APK 校验可运行 `python3 scripts/verify-native-apk.py app/build/outputs/apk/debug/xlib-debug.apk --sdk "$ANDROID_HOME" --report /tmp/xlib-android-native-audit.json`。
